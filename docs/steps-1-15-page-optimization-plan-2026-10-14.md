## 1. 衡量原则（来自 10–14 的精简）

1. 每页只回答一个问题；主内容直接回答它。
2. 完成条件（理解题）靠近结论，选做内容放后并折叠。
3. 一套记录语义：报告材料怎么来的，页面只有一个位置、一种说法；视图状态不等于记录。
4. 不重复讲：同一提示整页一次；多步共用的说明第一步展开、后面折叠。
5. 选做默认折叠。

## 3. 步骤 15：报告全文按节折叠

### 3.1 代码事实

- 页面顺序：清单（`labs/steps/report-lab.tsx:805-818`）→ 门槛卡（:819）→ 四步回归结果 `section.report-reference`（:820-828，始终展开）→ 回答三个问题（:829-886）→ 状态与提交（:899-938）→ 报告正文 `#report-preview`（:942-943，`ReportMarkdown`）。快捷链接是纯锚点（:814-816）。
- 渲染：`report-renderer.tsx` 用 react-markdown + remark-gfm + 一个 rehype 插件 `rehypeReportTableLabels`（:980-1008）；h1/h2/h3 只是样式覆盖（:991-993），没有任何分节容器或折叠。教师端 `teacher/reports.tsx:409` 共用同一组件。
- 导出 PDF 是打印当前页面（`printReport` :763-801，`globalThis.print()` :792；打印 CSS `styles.css:913` 只保留 `.report-body`）。**折叠起来的 `<details>` 不会被打印**，且 Ctrl+P 不经过 `printReport`。
- 二级标题顺序（`report_build.py:302-376`）：结论 → 真实指标比较 → 关键证据摘要 → 理解题答题记录 → 保存的实验快照 → 技术附录：保存的回归结果 → 附录：模型实验（有实验时）→ 数据检查 → 数据与方法说明 → 方法参考文献 → 报告溯源。库里旧报告可能带历史标题（如“附录：学生设计的模型”）。
- 四步回归结果面板（`regression-teach.tsx`）曾是 `<details>`（774e011 加入、3f83ebe 移除），现无折叠态；CSS 还留着 `.report-reference > summary` 规则（`report-finish.css:8-10`）。

### 3.2 改法

1. 在 `rehypeReportTableLabels` 之后加第二个 rehype 插件：把每个 h2 到下一个 h2 之间的节点包进 `details.report-section`，h2 放进 `summary`；白名单标题（结论、真实指标比较、关键证据摘要）与未知标题默认 `open`，其余折叠。h1 与开头的引用块不包。只在 `report-lab` 传 `foldSections`（`report-renderer-lazy.tsx:43` 的类型同步），教师端默认不折叠。
2. 打印：`printReport` 在现有 rAF 之前置 `expandAll`；另加 `beforeprint`/`afterprint` 监听，统一展开/恢复，覆盖 Ctrl+P。
3. 四步回归结果面板：报告状态为待评阅/已评阅时折叠为一行“四步回归结果 · 展开查看”，草稿或无报告时展开（恢复 `<details className="report-reference">`，CSS 现成）。
4. “真实指标比较”下那句指向“保存的实验快照”的提示保留，折叠后的节仍有可见的 summary。

### 4.2 改法（标签平等、显式记录）

1. **删除自动记录 effect**（6–8 `:533-547`，9 `:225-235`）和换图闪现（:514-542）。
2. **每张图下同一位置一个按钮**“把这张图记为本步报告材料”，调用现有 `recordCurrent(true)`（9 的 `onRecord` 加 `chosen` 参数并写 `material_chosen: true`）。已记录且当前图就是记录时按钮变为“已记录为本步报告材料”（禁用）；提交后文案变为“替换报告材料（之后在步骤 15 更新报告）”，复用 `MATERIAL_RECHOSEN_NEXT`。每步仍只保留一条材料。
