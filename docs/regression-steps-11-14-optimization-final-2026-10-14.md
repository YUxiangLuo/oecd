# 步骤 11–14 最终优化方案：让学生选不同的模型真的得到不一样的数值

> 建议文档，不含页面实现；文中每个数字都能用第 7 节的命令复现。综合三轮分析：[步骤 10–14 精简方案](regression-steps-simplification-2026-10-14.md)（已实施）、[模型空间核查](regression-model-space-check-2026-10-14.md)（现状 20,111 次估计全部符合生成规则）、本轮对课程方原始需求的对照与生成规则实验。当前行为以[技术手册](../技术手册.md)和[实验手册](../实验手册.md)为准。

## 0. 一页结论

1. **功能需求**：控制变量 8 个可选（含课程方点名的 6 个）、固定效应 5 个可选（含国家、行业、年份）、回归表六列齐全，差 4 处显示细节（显著性单独一列、Prob > F、Root MSE、常数项说明）。
2. **现状的问题**不在精度（默认模型 t 值 50–80），而在“改了设定数值不动”：12 类单项改动里 7 类变化 ≤ 3%。
3. **推荐的生成规则 P17**（GDP 混杂与关税同向并加强、开放度混杂与关税反向、所有国家共同的年份锯齿、校准下限上调、汇率贬值 8）：去掉汇率 +13%、去掉 GDP +9%、去掉开放度 −6%、去掉年份固定效应 −9%、只放当期 X −17%、换固定效应 −11%…；默认模型仍恢复真值；定义域、恒等式、零效应 Y、安慰剂全部通过；三个随机种子一致。
4. **四类按设计不变**（加人口、加 FDI、国家×年份固定效应、加 L2.X）保留，页面明说“为什么不变”；可选：让人口／FDI 有真实但不混杂的关系，使它们的系数带星而不改 X 的估计。
5. **页面侧**：显示课程设定值和每个实验相对设定值的偏差；预设重排为 3 必看 + 4 进阶；走势图下写“回归把这段变化拆成什么”；回归表补 4 处。
6. **不做**：第二批税率提高（收益小、副作用大）、GDP 反向混杂（走势图被抵消）、共同年份台阶（被控制变量吸收）、改噪声。

## 1. 课程方三条功能需求的对齐情况

### 1.1 控制变量 —— 已对齐，还多 3 个

| 课程方要的 | 工作台“自定义设定”里 |
| --- | --- |
| GDP（对数） | GDP 对数 |
| 人口增长率 | 人口增长率 |
| 贸易开放度 | 贸易开放度 |
| 汇率 | 汇率变动 |
| FDI | FDI 净流入占比 |
| 产业结构 | 制造业增加值占比（按 ICIO 计算） |
| 等等 | 增加值总额对数、出口强度（按 ICIO 计算） |

8 个都是复选框，每个可选当期或滞后 1 期（`gvcsim/regression/spec.py` 的 `CONTROLS`）。

### 1.2 固定效应 —— 已对齐，还多 2 个

国家 FE、行业 FE、年份 FE 各是独立复选框，另有国家×行业 FE 和国家×年份 FE（`FIXED_EFFECTS`）。默认勾国家×行业 + 年份，此时国家、行业显示“已包含”；取消国家×行业后可以单独勾。课程方说的“国家 + 行业 + 年份”也是一个预设实验。

### 1.3 回归表 —— 基本对齐，4 处小差距

课程方给了两种样式：Stata `regress` 输出和 Excel 六列表（变量、系数、标准误、t 值、近似 p 值、显著性），并说“均可，只需要清楚显示”。现在默认展开的是期刊式对比表（系数***（标准误）+ 固定效应是/否 + 观测值、年份、聚类数、R²、调整 R²、组内 R²、F），折叠在“查看单模型详细数字”里的是 Excel 式表（变量、系数带星、标准误、t 值、p 值、95% 区间、换算列，可导出 CSV）。

| 差距 | 现状（已核对代码） | 建议 |
| --- | --- | --- |
| 显著性单独一列 | 星号跟在系数后面（`regression-workbench.tsx` 详细表没有“显著性”列） | 加一列 |
| Prob > F | 后端 `f_p` 已算，前端只映射不显示（`regression-workbench-table.ts`） | 在“F（自由度）”旁显示 |
| Root MSE | 前后端都没有 | 后端加 `root_mse`，统计块加一行 |
| 常数项 | 只有无固定效应模型有（`estimation.py` 吸收固定效应后不加常数） | 保持，表下注一句 |

另建议把详细表默认展开，让课程方第一眼看到六列表。都是显示层改动。

7 类“不能”里，4 类是按设计不该变（加人口、加 FDI、L2.X 为零、国家×年份吸收），**3 类是设计没到位**：去掉 GDP、去掉开放度、去掉年份固定效应。原因：

- GDP 对 Y 的系数只有 0.08·β，第一批国家的额外增长每年 1.2%，到 2020 年只造成 0.004·β 的差异；开放度同理（0.0015·β × 每年 +2）。
- 共同年份趋势很小（噪声尺度 × ±0.4），而且 GDP 对数自带每年 2.5% 的线性增长，与开放度、汇率一起把线性的共同变化吸收了，所以去掉年份固定效应几乎没影响。

### 2.3 走势图：下降看得见，但“下降 ≠ 关税”没接到回归上

步骤 11 三组走势（相对加税前均值，份额）：第一批 2020 年 −0.054，第二批 −0.009，未加税 0.000。按生成规则拆第一批的 −5.4 个百分点：关税 X −1.6、汇率贬值 −3.1、GDP −0.6、开放度 −0.7（其余是噪声）。图上掉了 5 个多百分点，结论句说“X 每高 1 个百分点低 0.55 个百分点”，页面上没有一句话把两者接起来。第二批几乎看不见，因为第二批国家的对美出口份额 w 只有第一批的一半（货物单位均值 0.107 对 0.222）。

### 2.4 固定效应错选时偏差方向因 Y 而异的根因

Y 的单位水平按真实 ICIO 指标排名校准，真实数据里“对美出口份额高的单位”在不同指标上水平高低不同。验证：给单位水平人为加一项与 w 成比例的差异，“无固定效应”的估计可从 −0.07 连续变到 −1.02。不可能用一个参数让所有 Y 的固定效应偏差同向，除非放弃按真实排名校准。所以固定效应实验的文案只说“离设定值多远”。

## 3. 生成规则实验

### 3.1 方法

`scripts/teaching_variants.py` 把候选改动作为对 `gvcsim/regression/teaching.py` 常量的覆盖（GDP 的 γ、第一批额外增长、共同增长、汇率贬值、开放度的 γ 与第一批上升、共同年份趋势、校准下限），从 release 的源面板和出口份额用**生产生成器**重建教学面板，用**生产估计器**在 4 个默认 Y、零效应 Y 和一个恒等式 Y 上跑 11 种设定，同时跑定义域检查（`generated_problems`）、三组走势、按生成规则的拆分、60/40 拆分、L2.X 与无关控制是否为零、与 linearmodels 的系数对照。为此把生成器里三个硬编码数字提为常量（`COMMON_GDP_GROWTH`、`WAVE1_EXTRA_GDP_GROWTH`、`WAVE1_OPENNESS_RISE`），重建的面板与已发布的 31 列逐值相同。

### 3.2 候选的演进

偏差为估计幅度相对真值，+ 为高估。走势图列是步骤 11 默认 Y 在 2020 年相对加税前的变化（第一批 / 第二批 / 未加税，百分点）。

三个取舍：

- **GDP 混杂必须与关税同向。** 反向（P1）在回归上更“丰富”（一个高估一个低估），但走势图上第一批的下降被它抵消成 +0.3，学生在“先看数据”就看不到下降。
- **开放度反向混杂**让“去掉开放度”可见，代价是第一批的走势下降变浅（P11 −9.1 → P13 −3.6）。P17 用更大的汇率贬值和增长差把它补回到 −8.4。
- **年份固定效应**只能靠非单调的共同冲击来教：线性或台阶式的共同变化都被 GDP 对数（线性增长）等控制变量吸收（P14 −2%）；锯齿（2018 跌、2019 反弹、2020 再跌）不被吸收（P15 −10%）。走势图上三组会一起锯齿，正是年份固定效应扣掉的那部分。

### 3.6 否定结果与可选项

- **第二批税率提到 0.35 或 0.40**：第二批走势只多降 0.3–0.4 个百分点（w 小，X = w × τ 仍小），更多 Y 越出定义域，并把“去掉汇率”的偏差稀释到 9%。不做。第二批作为一课讲：“税率相同，但对美出口份额小，所以 X 小、下降小”。
- **人口／FDI 有真实但不混杂的关系**（事后改写，γ_人口 = 0.02·β、γ_FDI = 0.004·β）：它们的系数变得高度显著（p < 1e-11），X 的两年累计只变 0.7%。可选：生成器要把两者的 γ 真正用起来（现在 `MACRO_CONTROLS` 里的 0 没有参与生成）。教的是“系数显著 ≠ 影响 X 的估计”，但它不改变 X 的数值；按本轮目标不是必需。
- **噪声不动**：精度不是问题。

## 6. 风险与取舍

- **走势图变“乱”**：三组一起锯齿，第一批额外深 4.6 个百分点（现状是第一批单独深 5.4）。这是年份固定效应这一课的代价；F3 的拆分句要把“三组共同的变化”写出来。
- **第一批的下降大部分不是关税**（−8.4 中关税 −1.6）。这正是“控制变量决定数值”的体验来源，但结论卡要明确“回归算的是扣掉这些以后的关联”。
- **设定值会不会让学生“对答案”？** 显示放在计算之后；理解题不问设定值；报告标注“课程设定值”。
- **夸张与现实**：GDP 系数 0.5·β、增长差 4%、开放度反向都偏离现实量级；页面与报告已声明“课程按设定生成”。
- **重算 release 改变旧会话的报告数字**：报告按保存的设定在当前 release 重算。学期之间上线，或为旧学期保留 v12。
- **固定效应偏差方向不可统一**（2.4）：相关文案只说“离设定值多远”。
