# 回归步骤精简计划与阶段记录

基线：`b673e23`。目标是保留第 11–14 步及其计算、保存和材料要求，减少重复讲解与阅读门槛；不是把四步改成四种估计方法。

## 研究依据

- [ASA GAISE College Report 2016](https://www.amstat.org/asa/files/pdfs/GAISE/GaiseCollege_Full.pdf)，第 3、8–10 页：概念理解、情境、主动学习和软件输出解释。
- [IES Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/WWC/Docs/PracticeGuide/20072004.pdf)，第 9–11 页：示例与练习交替，随熟练程度逐渐减少指导；该项评级为中等证据。
- [NN/g Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/)：保留主任务必需内容，按需提供高级内容；不通过更多嵌套层级解决复杂性。
- [ASA p-value statement release](https://www.amstat.org/asa/files/pdfs/P-ValueStatement.pdf)：阈值不能替代科学判断，必须完整报告。
- [Callaway / Sant’Anna 多期 DID 说明](https://bcallaway11.github.io/did/articles/multi-period-did.html)：分批处理的对照选择和识别假设不能被简单四格替代。

这些材料支持教学原则，不直接证明某种页面布局更有效。学生试用仍需另行安排。

## 不变的契约

- 不改指标、估计算法、数据 release、schema、API、步骤路由或材料门槛。
- 保持 `run`、`qualified_run`、`reading_check` 格式、运行身份绑定及服务器确认语义。
- 保持固定理解题版本、题目/选项/答案键及旧进度。
- 区间跨 0 与停止推断严格区分；TWFE 保持描述性，网络保持探索性。
- 取消练习阅读限制不等于取消全局、逐事件期或冲击前诊断的推断限制。
- 不增加初级/高级模式、确认步骤、新保存字段或多层折叠。
- 仅支持 ≥1200px 桌面；数据库测试与浏览器验证在隔离环境进行。
