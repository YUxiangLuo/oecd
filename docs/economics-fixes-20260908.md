R04 是在二次确认已降级为“校准疑点”后作出的明确校准选择，不能重新描述成已证明的旧单位错误。D01 是按“修复所有问题”的要求修改既有发布设计，也不表示原来真实数据的逆矩阵已计算错误。

政策范围采用 [Proclamation 9693 光伏附件 Note 18(b)](https://www.govinfo.gov/content/pkg/FR-2018-01-25/pdf/2018-01592.pdf) 与 [Proclamation 9694 洗衣机附件 Note 17(b)](https://www.govinfo.gov/content/pkg/FR-2018-01-25/pdf/2018-01604.pdf) 中的明确名单，没有按泛化的“发展中国家”标签推断。加拿大、菲律宾属于洗衣机豁免，不能套用于光伏。土耳其自 2019-05-17、印度自 2019-06-05 取消两类豁免；新增 2019 年教学强度分别按 229/365、210/365 折算。[土耳其公告](https://www.govinfo.gov/content/pkg/FR-2019-05-21/html/2019-10761.htm)、[印度公告](https://ustr.gov/sites/default/files/Proclamation_9902.pdf)。行业映射、覆盖比例及行业年度税率仍是教学近似。

CR1 对照统一为 `G/(G−1) × (N−1)/(N−K)`，K 包含吸收的固定效应自由度。PanelOLS 的组修正提供 `G/(G−1) × (N−1)/N`，与其剩余自由度缩放结合后匹配。该开关的作用见 [linearmodels 官方协方差文档](https://bashtage.github.io/linearmodels/panel/panel/linearmodels.panel.covariance.ClusteredCovariance.html)。统一约定后收紧容差，并不取消少聚类、秩不足或识别条件的检查。

发布门禁保留原有源账户舍入容差：单元误差须同时超过 **1 Million USD 和 1%** 才构成实质性账户失败；仅触及单个界限仍按原规则披露。负 VA/TLS 或按有符号金额算得的区间外份额属于经济诊断；分子/分母比例不匹配、分解不闭合、聚合不一致和逆矩阵失败属于数学错误，不能发布。真实五年数据仍保留负值和舍入披露，输出数学检查全部通过。

## 首轮修复验证结果

- 后端全量：**635 passed**，覆盖率 **89.83%**，超过 85% 门槛。最初全量执行的两项失败均为旧提示/版本号断言；更新后再次全量通过。
- 前端：**367 passed**；`bun run build` 的 TypeScript 和 Vite 构建通过。
- Ruff 格式、静态检查及 mypy（53 个源文件）通过。
- 全表关税暴露以 DataFrame 连接与聚合独立计算，未调用生产生成循环。17,325 行固定/当期列最大绝对误差均小于 **1×10⁻¹⁶**，历史 8 条遗漏逐条恢复。
- 公开回归引擎共 **33** 组：11 组 TWFE 为 `ok` 且全部通过 PanelOLS 对照，最大标准误差异 **9.66×10⁻¹³**；另有 16 组 `invalid_design`、6 组 `insufficient`，均为 DID/事件研究的支持度或设计限制。验证没有将这些结果改成可推断，也没有把数值一致性当成因果识别证据。
- `agent-browser` 以独立学生账号实测第 10、13、14 步，并检查全部 15 个学生页面：无应用错误、浏览器脚本错误或文档溢出，经济诊断继续显示。长度原始系数约 −0.0863，图卡展示约 −0.000863；网络原始系数约 −826.9667，图卡展示约 −8.2697。加拿大 C27 的 2018 年关税记录为 0.00%，公告豁免说明可见。
- 新 release 冲击面板性能验收通过：单请求冷启动 **323.86 ms**；8 并发冷启动 p95 **573.60 ms**；40 次顺序请求 p95 **33.07 ms**；48 次、8 并发请求 p95 **392.35 ms**，均满足 500/1500 ms 门槛。此为认证中间件与 API 的进程内测试，不包含网络传输延迟。

## 未提交改动复审后的补充修复

复审发现的两项问题均已修复：

- **输出质检警告遗漏（P2）**：报告汇总同时读取输入质检的 `warning` 与输出质检 v4 的 `warnings`，合并去重，并触发诊断披露。回归测试从实际经济范围检查生成警告，写入测试 release，再通过报告构建验证 Markdown 和来源记录；正确的区间外份额仍允许发布。
- **负金额增长率被改写（P3）**：停止从截断过负值的对数代理量反推国家总额，改用有符号原始金额。平减指数不变时，`100 → −100` 现按 `(−100 − 100) / 100` 得到 **−200%**。国家行、完整行业分区和显式传入国家总额的行业子集均覆盖正负转换、零基数、平减与索引对齐。内部价格转换接口的行业子集调用需提供 `country_totals`；公开回归的控制变量和价格模式限制保持原契约。

本轮针对性验证 **60 passed**，回归模型与数值测试 **99 passed**，合计 **159 passed**；Ruff 格式、静态检查及 mypy 通过。上述首轮全量测试与浏览器结果为首轮记录，本轮未重新执行全部前后端测试。

对现有 v13 release 再次完成 38 个文件的完整性与契约验证。真实五年 385 条国家记录与 17,325 条行业记录的增长率交叉核验通过，GDP 与出口增长率最大绝对差异分别为 **6.59×10⁻¹⁶** 和 **6.80×10⁻¹⁶**；385 条单行业子集记录显式使用国家总额后也与全国结果一致。本轮未改变产物格式、版本或 release，无需重新生成数据。
