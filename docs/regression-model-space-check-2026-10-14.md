# 步骤 11–14 模型空间核查

> 当前 release 上，学生可构造的模型（7 种 X 滞后组合 × 13 种固定效应组合 × 13 种控制变量设置）对 17 个 Y 的估计，逐项与教学数据的生成规则对照。生成规则见 `gvcsim/regression/teaching.py`，核查脚本见 `scripts/check_model_space.py`。

- 估计次数：20111；设定数：1183；Y：17。
- 生成规则：Y = 单位水平 + β·(0.6·X + 0.4·L1.X) + (−0.0095·β)·汇率变动 + β·(0.08·ΔGDP对数 + 0.0015·Δ开放度) + 噪声与共同年份趋势；人口增长率、FDI 与 Y 无关；没有两年后关联；汇率、GDP 增长、开放度上升与第一批加税相关（混杂）。

## 0. 结论与解读（2026-10-14，release `93c4752…`）

**结论：学生在步骤 11–14 能构造的全部模型（1,183 种设定 × 17 个 Y，共 20,111 次估计）都按教学数据的生成规则行事，没有发现与构造思路相悖的结果。** 具体地：

- 估计器正确：20,111 次全部通过与 linearmodels 的系数对照，没有报错、没有停止推断。
- 模型正确时恢复预设：单位（国家×行业）+ 年份（或国家×年份）固定效应、三项混杂控制在内（或被国家×年份吸收）的 570 个设定里，569 个的两年累计与 β 的偏差在 2.5% 以内或区间包含 β；当年／上年项恢复 60/40 拆分；加入 L2.X 时其区间 285/285 包含 0；汇率、开放度斜率全部包含预设值。
- 混杂与遗漏按设计显现：漏掉汇率变动时 15/15 个 Y 的累计关联被高估 18–23%；汇率只取滞后 1 期同样高估 15–22%（滞后的混杂因素替代不了当期的）；只放当期 X 时 15/15 个 Y 低估 14–19%（介于 0.6|β| 与 |β| 之间）。
- 无关控制如其名：人口增长率、FDI 的系数 180/180 区间包含 0（最小 p = 0.054），加入后累计关联不变；3 个 ICIO 派生控制加入后累计关联不变。
- 零效应 Y（后向复杂 GVC 生产份额）在正确设定下 19/19 区间包含 0；在错误设定下 111/150 次“方向明确”（错误设定也能显著）。
- 恒等式逐位成立：前向 GVC 总份额 = 简单 + 复杂、纯国内 = 1 − 其余三项、加权总度 = 入度 + 出度，在全部 1,183 个设定下每项系数相等；国内增加值出口占比与外国增加值项占比的 X 关联在正确设定下互为相反数（差 < 0.01）。GVC 位置指数（比值，无预设 β）在正确设定下 19/19 为负。

**第 1 节表中的“未通过”都是同一份数据的抽样波动，不是构造或估计问题。** 三组各对应一次独立事件：简单 GVC 生产份额在国家×年份固定效应下累计 −0.3049（偏差 +1.6%，z = −2.1；该固定效应吸收了国家×年份噪声，区间只有 ±1.5%，13 种控制设置下估计相同，所以同一事件被计 26 次）；加权出度在默认模型下 −2047（偏差 +2.4%，z = −2.3，入度与总度相应受影响）；后向 GVC 生产总份额的 GDP 斜率 −0.068 对预设 −0.036（z = −2.2，GDP 的组内变化小、区间宽）。约 50 个独立检查里出现 3 次 2 个标准误左右的偏离，与基准评估记录的 93% 左右区间覆盖率一致；多种子评估见 `benchmarks/teaching_design_v*.json`。

**两点设计层面的观察，供决定是否调整生成规则：**

1. “去掉 GDP 对数”这个预设实验几乎不改变结果（17 个 Y 里累计关联变动 ≤ 3%）。按生成规则，GDP 与开放度的混杂很弱（第一批国家的额外增长 0.012·t，乘以 0.08·β），所以这项实验教的是“弱混杂因素去掉也无妨”，而不是遗漏变量偏误；若希望它和汇率一样可见，需要加大第一批国家的增长差异或 GDP 的 γ 系数。
2. 固定效应错误时偏差的方向与大小因 Y 而异（“国家 + 行业 + 年份”下从 −48% 到 +83%，“无固定效应”下长度 Y 达 +283%），错误设定的区间仍包含 β 的比例从 7%（前向段长度）到 95%（后向段长度）不等。这与方案中“凑巧接近不代表模型对”的意图一致，但手册里可以写明这一点。
