# 步骤 11–14 模型空间核查

> 当前 release上，学生可构造的模型（7 种 X 滞后组合 × 13 种固定效应组合 × 13 种控制变量设置）对 17 个 Y 的估计，逐项与教学数据的生成规则对照。生成规则见 `gvcsim/regression/teaching.py`，核查脚本见 `scripts/check_model_space.py`。

- 估计次数：20111；设定数：1183；Y：17。
- 生成规则：Y = 单位水平 + β·(0.6·X + 0.4·L1.X) + (−0.0095·β)·汇率变动 + β·(0.5·ΔGDP对数 + -0.006·Δ开放度) + 噪声与共同年份趋势；人口增长率、FDI 与 Y 无关；没有两年后关联；汇率、GDP 增长、开放度上升与第一批加税相关（混杂）。

## 0. 结论与解读（2026-10-14 第二版，v13 release `8565f226…`）

本节手写；第 1、2 节由 `check_model_space.py report` 从 `dogfood-output/model-space-v13/runs.jsonl` 生成（摘要在 `benchmarks/model_space_v13.json`）。v12 的第一版结论见 git 历史（提交 `501afbc`）。

**结论：v13（最终方案的 P17）下，学生在步骤 11–14 能构造的全部模型（1,183 种设定 × 17 个 Y，共 20,111 次估计）都按教学数据的生成规则行事；v12 时“改了设定数值几乎不变”的三类实验（去掉 GDP 对数、去掉贸易开放度、去掉年份固定效应）现在都朝设计的方向偏离设定值。** 具体地：

- 估计器正确：20,111 次全部通过与 linearmodels 的系数对照，没有报错、没有停止推断。
- 模型正确时恢复预设：单位（国家×行业）+ 年份（或国家×年份）固定效应、三项混杂控制在内（或被国家×年份吸收）的 570 个设定里，558 个的两年累计与 β 的偏差在 2.5% 以内或区间包含 β；当年／上年项 554/570 恢复 60/40 拆分；加入 L2.X 时其区间 285/285 包含 0；汇率、GDP、开放度斜率各 180/180 包含预设值（−0.0095β、0.5β、−0.006β）。
- 混杂与遗漏按设计显现（相对预设 β）：漏掉汇率变动 15/15 个 Y 高估 10–15%；漏掉 GDP 对数 15/15 高估 6–11%；漏掉贸易开放度 15/15 低估 4–9%（其中 7 个 Y 的区间仍含 β：去掉一个混杂后区间变宽，这项判定按估计点的偏离计）；只留国家×行业固定效应 90/90 低估 7–22%（共同年份锯齿被算到 X 上）；汇率只取滞后 1 期仍高估 12–20%；只放当期 X 时 285/285 低估 14–20%（介于 0.6|β| 与 |β| 之间）。
- 无关控制如其名：人口增长率、FDI 的系数 180/180 区间包含 0，加入后累计关联到小数第三位不变；3 个 ICIO 派生控制加入后同样不变。
- 零效应 Y（后向复杂 GVC 生产份额）在正确设定下 19/19 区间包含 0；在错误设定下 112/150 次“方向明确”（错误设定也能显著）。
- 恒等式逐位成立：前向 GVC 总份额 = 简单 + 复杂、纯国内 = 1 − 其余三项、加权总度 = 入度 + 出度，在全部 1,183 个设定下每项系数相等；国内增加值出口占比与外国增加值项占比的 X 关联在正确设定下 133/133 互为相反数（差 < 0.01）。GVC 位置指数（比值，无预设 β）在正确设定下 19/19 为负。

**第 1 节表中的“未通过”都是同一份数据的抽样波动，不是构造或估计问题。** 它们来自两次独立事件（噪声抽样与 v12 相同，release 种子 20260913 未变）：

1. 加权出度在默认模型下两年累计 −2050（偏差 +2.5%，恰在门槛上；标准误约 20，z ≈ 2.5），加 L2.X 后 −2106（+5.3%，区间上界 −2005 刚好不含 −2000）；同一噪声使加权总度的当年项 −2481 对 0.6β = −2400（+3.4%），于是“恢复 β”12 次、“60/40 拆分”16 次、“无关控制／ICIO 控制不改变 β”的加权出度各 6、4 次都记为未通过，而这些设定下的累计彼此只差 1–2 个单位，说明加控制本身没有改变 β。
2. 简单 GVC 生产份额在国家×年份固定效应下累计 −0.3049（偏差 +1.6%，该固定效应吸收了国家×年份噪声，区间只有 ±1.5%，13 种控制设置下估计相同，所以“仅看区间”一项被计 26 次，“无关控制／ICIO 控制不改变 β”各 6、4 次）。按“偏差 ≤ 2.5%”它通过恢复判定。

约 50 个独立检查里出现 2 次 2 个标准误左右的偏离，与 200 种子基准（`benchmarks/teaching_design_v13.json`）的两年累计 95% 区间覆盖率 91.5%–95.5%（16 个有预设 β 的 Y 的均值 93.3%）一致。基准共估计 17 个 Y，GVC 位置指数没有单一预设 β，不计入覆盖率；非零 β 的 Y 的平均偏差都在 β 的 0.15% 以内，显著率 200/200，零效应 Y 的假阳性率 8.0%。
