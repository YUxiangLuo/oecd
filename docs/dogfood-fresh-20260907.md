**项目分析**

系统核心为 15 步全球价值链课堂实验。Python 离线管线计算贸易、生产、长度及网络指标，生成面板、控制变量、冲击数据和诊断，并用哈希清单及原子符号链接发布；浏览器读取发布产物进行比较、回归和报告交互。FastAPI 承担鉴权、数据读取、回归与课堂接口；PostgreSQL 保存账号、会话和报告。

重点风险集中在三处：浏览器自动保存与在途编辑/多标签页竞争；会话、令牌和报告跨 release 的隔离；回归结果、学生分析与已评分报告之间的快照一致性。当前完整的停止推断诊断也属于可提交教学证据，不能把它当作可推断估计。项目只维护至少 1200px 的桌面界面，未增加手机适配。

**发现与处理**

1. 本地 Nginx 使用当前用户运行，而默认 `client_body_temp_path` 指向系统目录。较大的回归会话触发临时文件写入失败，第 11 步保存返回 500；另用 64KB 请求重复复现两次。已在本地配置中指定专属可写 `client_body_temp_path` 和 `proxy_temp_path`。修复后 64KB 请求正确到达应用并返回预期 422，完整大记录课程从新账号重跑通过。
2. `dogfood_report_snapshots.py` 假定基准结果一定含 `qualified_run`，当前课程的完整停止推断诊断不满足这一假定，导致测试自身 KeyError。已保留原有可推断结果断言，并增加诊断路径的精确快照、报告引用及旧评分清理断言。真实数据两轮通过；本轮实际未触发保留可推断关税基准的分支，不能用诊断路径结果代替该分支实测。
3. `dogfood_sync.request` 对所有 HTTP 错误直接解析 JSON，遇到 Uvicorn 纯文本 503 时掩盖了实际过载原因。已保留非 JSON 错误的状态码和文本，新增三项回归验证。没有改变应用的限流或并发保护。

初次测试配置问题另行区分：数据计算完成前启动过一次后端测试，发现产物尚未生成后停止，最终全量结果来自完整新 release；故障代理首次未串入浏览器路径，修正接线后重复通过；第一次 A/B 只有发布 ID 不同而数值相同，测试正确拒绝，随后重新计算数值不同的对照数据并两轮通过。这些初次尝试不计入产品缺陷或通过数量。

**性能与容量**
