# 实验完成度与可信边界

- 步骤 1–15：会话中的题库版本和答案由服务端重新判分，全部正确即完成。
- 步骤 16：当前学生存在服务端生成的报告即完成。
- 实验筛选、图表和回归运行不影响步骤完成度。

系统不签发答题或回归凭证，也不记录证据事件。答题接口返回规范化答案，浏览器把它保存进会话；每次读取完成度时都会重新判分。因此客户端若已经知道正确答案，可以直接构造相同数据并通过。这是可信课堂环境的明确取舍，不适用于考试。

回归步骤保存最近一次 `{settings, design, result}`。报告直接使用这份结果，不复算；缺失或格式不正确的可选运行会标记为未记录，不阻塞报告。

浏览器不使用本地实验缓存。服务器保存每个学生的一份完整会话，最后写入生效；多个标签页并发编辑可能互相覆盖。

重新生成报告只更新当前报告，不修改已经提交的快照。再次提交会覆盖当前提交，并把评分状态重置为待评阅。
