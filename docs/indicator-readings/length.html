生产长度与 GVC 位置指标说明

生产长度刻画增加值在连续生产中被计入总产出的平均次数，而不是跨境次数或经过国家数。

当前课程口径
指标基于 OECD ICIO 2023 edition 的 2016–2020 年表，采用 Wang、Wei、Yu、Zhu 的生产长度分解。 课程同时呈现前向长度、后向长度和二者构成的 GVC 位置指数。

1. 操作性定义

某段生产长度 = 该段活动诱发的累计总产出 ÷ 该段关联增加值

当关联增加值为正时，这个比值可理解为增加值加权的平均生产阶段数。它反映的是投入产出账户中生产活动的累计程度，不等于一件产品实际经过的企业数、国家数或边数。

2. 前向与后向视角

视角追踪方向主要字段
前向从增加值创造端出发，追踪到最终吸收。PLv、PLv_D、PLv_RT、PLv_GVC
后向从最终产品端回溯其初始增加值来源。PLy、PLy_D、PLy_RT、PLy_GVC

D、RT 与 GVC 分别表示纯国内、传统贸易和全球价值链生产段。分段长度是各段条件下的比值，不能直接相加为总长度。

3. 为什么国内加工也会增加长度

长度统计连续生产过程中的累计产出。即使没有新增跨境，一项中间投入在国内继续加工，也会增加累计生产阶段。因此“生产链更长”不能改写为“跨境更多”。

Position on Global Value Chains

4. GVC 位置指数

GVCPs = PLv_GVC ÷ PLy_GVC
读数在这一指标口径下的含义
GVCPs > 1前向 GVC 长度相对更长，通常称为相对更上游。
GVCPs = 1前向与后向 GVC 长度相当。
GVCPs < 1后向 GVC 长度相对更长，通常称为相对更下游。
写作边界：“相对上游”不是“更先进”“附加值更高”或“议价能力更强”的同义词。它只描述前向与后向 GVC 段长度的相对关系。

5. 数值与比较边界

  • 分母缺失、非有限或绝对值不超过 1e-12 时，相关长度或位置指数不可用，不能强行填 0；负分母仍按有符号比值保留。
  • 当基础账户存在负增加值时，比值是有符号账户加权，不再保证普通加权平均的区间性质。
  • 比较国家或年份时，应固定行业层级、价格口径和数据版本。
  • Pos_TPL 比较总生产长度，GVCPs 比较 GVC 段长度，二者不是同一指标。
