GVC 生产分解指标说明

识别增加值通过何种生产路径被最终使用：纯国内、传统贸易、简单 GVC 或复杂 GVC。

当前课程口径
指标基于 OECD ICIO 2023 edition 的 2016–2020 年表，采用 Wang、Wei、Yu、Zhu 的生产活动分解框架。 前向口径从增加值创造地追踪去向，后向口径从最终产品回溯增加值来源。

1. 四类生产活动

类别判定方式直观含义
纯国内生产生产与最终吸收均在国内，没有跨境。服务本国最终需求。
传统贸易增加值随最终品直接出口，只跨境一次。跨境后直接进入国外最终需求。
简单 GVC增加值随中间品跨境一次，随后被最终吸收。参与国外生产，但不再发生第二次跨境。
复杂 GVC至少一次由中间品承载，最终吸收前累计跨境至少两次。经过第三国或再出口等更长的跨境路径。

2. 前向增加值分解

SVA = 1_VA_D + 2_VA_RT + 3a_VA_GVC_S + 3b_VA_GVC_C
SVA从增加值来源端核算的生产活动总增加值。
1_VA_D纯国内生产增加值。
2_VA_RT随最终品直接出口的传统贸易增加值。
3a_VA_GVC_S简单 GVC 增加值。
3b_VA_GVC_C复杂 GVC 增加值。
复杂 GVC 生产份额 = 3b_VA_GVC_C ÷ SVA

3. 后向最终产品分解

FGY = 1_FGY_D + 2_FGY_RT + 3a_FGY_GVC_S + 3b_FGY_GVC_C
FGY从最终产品生产端核算、为最终需求服务的全球增加值总量。
1_FGY_D本国最终品中由本国生产且全程不跨境的增加值。
2_FGY_RT最终品直接出口中包含的本国增加值。
3a_FGY_GVC_S从最终品端回溯，只经历一次中间品跨境的增加值。
3b_FGY_GVC_C从最终品端回溯，累计跨境至少两次的复杂 GVC 增加值。
资料校订：委托方 DOCX 和 XLSX 最后一列重复写成了 3b_VA_GVC_C。结合其表中含义和 Wang 等（2017）的后向分解，正确字段应为 3b_FGY_GVC_C；当前课程已使用正确字段。

4. 解释边界

  • 简单与复杂描述跨境生产路径，不是产品技术含量、企业能力或收益率评级。
  • 复杂 GVC 份额更高不自动表示“更先进”，也不自动表示风险更高或更低。
  • 前向与后向是两种记账视角，不能把同一数值机械相加。
  • 比较国家或年份时，应固定指标、行业聚合、价格口径和数据版本。
