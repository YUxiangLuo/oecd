# 步骤 2–5 指标文献组件

课程页面在各步主要操作之后提供一个默认折叠的“延伸阅读 · 指标相关文章”区域。展开后可在当前页面预览 PDF，也可在新标签页打开。

当前 `frontend/public/readings/` 中的文件都是界面示范文档，不是正式论文或指定阅读。正式材料确定后：

1. 将 PDF 放入 `frontend/public/readings/`；
2. 在 `frontend/src/labs/steps/indicator/indicator-reading-library.tsx` 的 `INDICATOR_READINGS` 中更新文件名、标题、作者、年份、出版物和简介；正式论文有 DOI 或来源页时填写可选的 `sourceUrl`；
3. 每一步可以配置一篇或多篇文档，不需要修改步骤组件；
4. 保留“可选阅读，不影响本步完成”，除非课程规则明确要求阅读材料参与考核。

组件始终提供“新标签页打开 PDF”，并在内嵌预览下显示恢复提示；不支持浏览器内嵌 PDF、预览空白或文件加载失败时，学生仍有明确的打开和求助路径。

示范配置中特意为步骤 2 放入两篇 PDF，用于验证多文档切换；步骤 3–5 各放入一篇。
