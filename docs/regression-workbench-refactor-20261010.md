# 回归部分重构方案：学生自己设计回归模型（2026-10-10）

本文档整理 2026-10-10 关于“让学生自由设计回归模型”的讨论：雇主的需求、现状、可行性、用真实数据做的检验、建议的最小重构方案和分阶段计划。**尚未确认的事项集中列在最后一节，确认前不开始实施。**

## 1. 雇主的需求

### 1.1 最新反馈（微信）

用户向雇主说明“关税与回归的部分，用美国给全球各国加关税为核心来串联”，雇主回复：

> 我觉得可以，主要是能够让学生能够有些自由选择的空间来设计回归模型，包括选取控制变量，固定效应，滞后项之类的。

结论：**“美国加关税”这条主线已获认可**；新增的要求是**学生能自己设计模型**。

### 1.2 较早的书面建议（《回归分析步骤建议》）

这份文档是雇主针对很早以前的 demo 写的，共 4 条：

1. **滞后项**：核心自变量和所有可选变量都可以选“滞后 0/1/2/3 期”，用来看贸易政策的滞后效应和长期效应。回归表里不滞后的不标；滞后的标为 `L1.变量名`、`L2.变量名`、`L3.变量名`（例如 `L1.简单平均关税率`）。
2. **固定效应**：控制变量后面加一列固定效应选项，可以自由勾选“国家/地区 FE”“行业 FE”“年份 FE”。
3. **回归表格**：导出的表附上 R²、调整 R²、近似 F 统计量、观测值，以及控制了哪些固定效应；并加注：“显著性基于演示用近似 p 值，*** p<0.01, ** p<0.05, * p<0.1。括号内为标准误。系数为标准化系数。”
4. **保存结果**：可以自定义保存为“结果XX”，以便把多个回归结果合在一起展示。

文档附的旧 demo 截图还显示了雇主期望的界面：

- **核心自变量（X）**：可勾选的“贸易政策冲击指标”：简单平均关税率、加权平均关税率、关税离散度、NTM 覆盖率、NTM 频率指数、TBT 通报数。
- **控制变量**：勾选 GDP、人口、贸易开放度、汇率、外商直接投资。
- **操作**：“运行回归”“保存到对比（已存 2）”“导出 CSV”；页面标签有“国家/地区 FE”“行业 FE”“年份 FE”。
- **回归表**：变量、系数、标准误、t 值、近似 p 值、显著性，含常数项；表头写明因变量和固定效应组合。

### 1.3 对需求的理解

雇主要的是一个**简化版的 Stata 式建模工作台**：X 仍是关税暴露，学生围绕它选控制变量、固定效应和滞后期，把多次结果保存下来并排比较。它与已认可的“美国加关税”主线不冲突。

## 2. 现状

### 2.1 现在的模型

步骤 11–14 用同一个固定模型，只换 Y：

> Y = β·X + 国家×行业固定效应 + 年份固定效应 + 误差

- **X**：关税暴露 = 首年（2016）对美出口份额 w × 加征税率 τ（v8：只对被加税国家的货物行业征税）。这是**唯一的解释变量**，β 是要估计的数。
- **国家×行业固定效应**：扣掉每个国家×行业自己的平均水平。
- **年份固定效应**：扣掉每一年所有国家×行业的共同变化。
- 标准误按国家聚类。
- **学生能选的只有 Y**（点条形图的哪一条）；控制变量、固定效应和滞后都不能改。

### 2.2 代码结构（与重构相关的部分）

| 位置 | 现状 |
|---|---|
| `gvcsim/regression/contracts.py` | `RegressionRequest` 只有 `outcome`、`baseline`；所有 HTTP 结构 `extra="forbid"` |
| `gvcsim/regression/design.py` | `RegressionDesign` 固定：`controls` 恒为空，`regressors` 只有 X，`control_mode` 恒为 `none` |
| `gvcsim/regression/model.py` | `PreparedModel` 已支持多个解释变量（`xcols`） |
| `gvcsim/regression/estimation.py` | `twoway_demean` 轮流扣“单位”和“年份”两组平均；`drop_collinear_columns` 会删掉被吸收的列 |
| `gvcsim/regression/benchmark.py` | 用 linearmodels `PanelOLS`（单位 + 年份）独立复算，系数与标准误不一致时抑制推断 |
| `gvcsim/regression_routes.py` | `/api/regression/run` 按 `(outcome, baseline)` 缓存 |
| `gvcsim/report_saved_run.py` | 报告只接受固定设计的保存结果（`_FIXED_DESIGN`、`model_snapshot` 完全相等） |
| `frontend/src/regression.tsx` | 每步一张条形图（一条一个 Y），点哪条保存哪条 |

历史：应用早期有过控制变量功能，提交 7e19e4a（2026-09-22，“Refocus regression workflow on fixed teaching model”）为聚焦教学把它删掉了。

### 2.3 现有数据

- 年份只有 **2016–2020**（OECD ICIO 2023 版最晚到 2020 年；本地和服务器原始数据都只有这 5 年）。加税从 **2018** 年开始。
- 教学面板 `panel_teaching.csv`：75 国、3,200 个国家×行业、16,000 条记录。
- 面板里已有的控制变量**全部是国家层面的**（同一国家同一年的所有行业取值相同）：
  - 按 ICIO 计算：`log_gdp_proxy`、`gdp_proxy_growth`、`log_exports_proxy`、`exports_proxy_growth`、`export_intensity`、`manufacturing_va_share`；
  - 模拟宏观变量（当初为旧 demo 生成，正好对应截图里的 GDP、人口、汇率、FDI）：`macro_log_gdp_usd`、`macro_log_population`、`macro_log_gdp_per_capita`、`macro_exchange_rate_change`、`macro_fdi_inflow_gdp`。
  - 两个增长率变量（`gdp_proxy_growth`、`exports_proxy_growth`）2016 年全部缺失。
- **Y 是课程生成的**：Y = 基线水平（按真实指标的排名校准，每个国家×行业不同）+ β·X + 噪声（含国家×年份成分）。Y **不依赖任何控制变量，也不依赖滞后的 X**。

## 3. 需求评估

**结论：需求合理，但用现有数据只能部分实现。**

### 3.1 合理之处

- 选控制变量、固定效应和滞后期，是计量经济学最核心的练习，适合 GVC 与贸易政策课程。
- 不推翻已认可的“美国加关税”主线：X 不变，只是让学生在 X 周围搭模型。

### 3.2 限制

1. **控制变量和滞后在现有数据上几乎不改变结果。** 因为 Y 只由基线水平、X 和噪声生成，学生加控制变量或滞后项，X 的估计值基本不动，控制变量和滞后项的系数约为 0。这能教“结论是否稳健”，教不了“漏掉控制变量会造成偏误”。
2. **固定效应的选择会显著改变结果**（见 4.2）。每个国家×行业的基线水平不同，而且与 X 相关，不扣掉就会偏。这一点不需要改数据就能教。
3. **滞后期受数据年份限制**（2016–2020，2018 年起加税）：
   - X 的滞后 1 期：可以估计，样本少一年（2017–2020）；滞后 X 与当期 X 只在 2018 年不同，区间会较宽。
   - X 的滞后 2 期：只有 2020 年不为 0，估计很弱。
   - X 的滞后 3 期：在 2020 年之前全部为 0，**无法估计**。
   - 控制变量的滞后 1–3 期都能算，但每滞后一期样本少一年（滞后 3 期只剩 2019–2020 两年）。
   - 补下载更早年份（如 2011–2015）不能改善 X 的滞后（加税年份和数据结束年份不变），只能增加“加税前”的年份。
   - **Y 的滞后（动态面板）**在 5 年数据上不可靠，不应开放。
4. **控制变量都是国家层面的**：选了“国家×年份”或“国家 + 年份”类固定效应时，它们会被吸收，必须在页面上说明“已被固定效应吸收”。
5. **与“步骤 10–15 简单好看”的既有要求有张力**：解决办法是保留默认模型，把建模工作台做成可选面板（见第 5 节）。

## 4. 用真实数据做的检验（2026-10-10，release `97643f7c4317428db1baa5c872909cc0`）

以下由独立脚本在 `panel_teaching.csv` 上计算，标准误按国家聚类；区间的小样本校正口径与页面略有不同，只用于判断方向和量级。

### 4.1 换控制变量、固定效应、滞后（步骤 11 默认 Y：外国增加值项占比，设定值 −0.55）

| 模型 | X 的估计值 | 95% 区间 | 说明 |
|---|---|---|---|
| 单位 + 年份（现在的默认） | −0.551 | [−0.565, −0.537] | |
| 加控制变量（`log_gdp_proxy`、`export_intensity`） | −0.550 | [−0.564, −0.537] | 两个控制变量的系数约为 0 |
| 单位 + 国家×年份 | −0.552 | [−0.556, −0.547] | 区间明显变窄（噪声里有国家×年份成分） |
| 单位 + 国家×年份 + 控制变量 | −0.552 | 同上 | 两个控制变量被固定效应吸收 |
| 单位 + 行业×年份 | −0.552 | [−0.568, −0.535] | |
| 加 X 的滞后 1 期 | −0.546 | [−0.562, −0.530] | 滞后项约为 0；样本 16,000 → 12,800 |

### 4.2 自由勾选固定效应（雇主建议的勾选方式）

| 固定效应 | 步骤 11（设定值 −0.55） | 步骤 13（设定值 −1.82） |
|---|---|---|
| 不加 | −0.19 | −5.82 |
| 只加年份 | −0.19 | −6.04 |
| 只加国家 | −0.00 | −6.44 |
| 只加行业 | −0.62 | −2.98 |
| 国家 + 行业 + 年份 | −0.51 | −3.19 |
| 国家×行业 + 年份（现在的默认） | **−0.55** | **−1.82** |

结论：固定效应选得不对，估计会明显偏离设定值；选对了才回到设定值。这正是雇主想要的“可以设计的明显结果”，而且**不需要重新生成数据**。

## 5. 设计原则

1. **默认模型不动**：步骤 11–14 现有的默认模型、条形图、结论句、报告主结果和手册数字都保持不变。
2. **建模工作台是附加的**：每步在条形图下面加一个默认折叠的“自己设计模型”面板。
3. **默认设定是工作台的第一列**，学生的每次尝试与它并排比较。
4. **数据不重算**（最小版本）：只用现有面板中的变量。
5. **对不能估计的选择给出原因**，不静默失败（例如 X 的滞后 3 期）。

## 6. 功能设计

### 6.1 模型设定（学生可选）

| 项目 | 选项 | 说明 |
|---|---|---|
| 核心自变量 | 关税暴露 X（固定） | 每个变量旁可选滞后 0/1/2/3 期 |
| 控制变量 | 从白名单勾选（建议最多 3–5 个），每个可选滞后 0/1/2/3 期 | 名称对应雇主截图：GDP、人口、贸易开放度、汇率、外商直接投资；具体清单待确认 |
| 固定效应 | 勾选：国家×行业 FE（默认）、国家 FE、行业 FE、年份 FE；可都不勾 | 都不勾时加常数项；嵌套或被吸收的固定效应自动说明 |
| 滞后标注 | 回归表里写 `L1.变量名`、`L2.变量名`、`L3.变量名` | 按雇主建议 |

服务端校验：变量与滞后期必须在白名单内；无法估计的组合（如 X 的滞后 3 期全为 0、样本不足）返回明确原因。

### 6.2 回归结果表

- 列：变量、系数、标准误（括号内）、t 值、p 值、显著性星号；各固定效应是否控制（是/否）；R²、调整 R²、F 统计量、观测值、聚类数。
- 注释（措辞待确认）：显著性星号含义；“括号内为标准误，按国家聚类”；系数口径（原单位或标准化）。
- 被固定效应吸收或因共线被删掉的变量，在表下注明。

### 6.3 保存与对比

- 每次计算后可命名保存（默认“结果1”“结果2”…），学生可改名。
- 一张多列对比表：任选若干已保存的结果并排展示（像论文里的多列回归表），第一列为默认模型。
- 可导出 CSV。

### 6.4 报告

- 自定义结果**不替换**本步保存的主结果（条形图和结论句仍用默认模型），另存为“我试过的设定”。
- 报告附录增加“学生设计的模型”对比表，并写明每列的设定。

## 7. 技术重构（最小版本）

### 7.1 后端

| 文件 | 改动 |
|---|---|
| `gvcsim/regression/contracts.py` | `RegressionRequest` 增加可选 `spec`：`controls`（白名单内的变量及滞后期）、`x_lags`（0–3 的集合）、`fixed_effects`（勾选集合）；保持 `extra="forbid"` |
| `gvcsim/regression/design.py` | `RegressionDesign` 携带 `spec`，由它生成 `regressors`、`controls`、公式文字；**不传 `spec` 时序列化结果必须与现在逐字相同**，以免已保存结果和报告校验失效 |
| `gvcsim/regression/model.py` | 按单位、年份排序后用 `groupby(entity).shift(k)` 生成滞后列；构造 `国家`、`行业`、`国家×行业` 等分组列；`sample_flow` 记录因滞后或缺失减少的样本 |
| `gvcsim/regression/estimation.py` | `twoway_demean` 改为接受任意多组分组（交替投影法，现有算法自然推广）；无固定效应时加常数项；自由度按吸收的固定效应计算；被吸收的列沿用 `drop_collinear_columns` 并返回名单 |
| `gvcsim/regression/benchmark.py` | 独立对照改用 linearmodels `AbsorbingLS`（支持任意组固定效应），或 `PanelOLS(other_effects=…)`；需先验证可行性 |
| 统计量 | 新增 R²（口径待确认）、调整 R²、F 统计量（聚类稳健的 Wald F）、聚类数 |
| `gvcsim/regression_routes.py` | `spec` 计入缓存键；服务端校验白名单 |
| 会话与报告 | 新增“已保存的自定义结果”材料（名称、设定、结果）；`report_saved_run.py` 现有校验不变，另加自定义结果的解析与附录表 |

### 7.2 前端

- 新组件 `RegressionSpecPanel`：步骤 11–14 条形图下方，默认折叠；变量勾选与滞后选择、固定效应勾选、“计算”按钮；不能估计时显示原因。
- 新组件“结果对比表”：已保存结果的多列表、改名、删除、导出 CSV。
- 面板内一句说明：Y 由课程按设定生成；控制变量和滞后在本课程数据中不影响 Y，可用来检验结论是否稳健；固定效应的选择会明显影响结果。

### 7.3 不改动

- 数据生成（v8）、默认模型、条形图、结论句、换算、报告主结果与手册中的现有数字。

## 8. 测试与核对

- **单元测试**：每种固定效应组合、滞后（含无法估计的情况）、被吸收变量、无固定效应加常数项、默认 `spec` 的序列化与现在完全一致。
- **独立复算**：扩展第 28 轮的 `regress.py`，对一组代表性设定逐一比对系数、标准误、区间、p 值、R² 与 F。
- **报告核对**：扩展报告逐数核对脚本，覆盖新附录表。
- **浏览器测试**：模拟学生设计、保存、改名、对比、导出 CSV、生成报告。
- **手册**：新增“自己设计模型”一节与截图。

## 9. 分阶段计划

1. **样板**：只在步骤 11 实现工作台（后端完整，前端一个步骤），部署到演示站给雇主确认。
2. **推广**：确认后推广到步骤 12–14，加入保存、对比与 CSV 导出。
3. **报告与手册**：报告附录、实验手册、技术手册、测试与独立复算。
4. **可选**：若雇主希望控制变量和滞后也产生明显差异，再评估数据 v9（在生成 Y 时埋入混杂因素与滞后效应；所有页面数字、手册和复核都要重做）。

## 10. 不在最小版本中的内容

- 数据 v9（让控制变量、滞后真正改变 Y）。
- Y 的滞后（动态面板）。
- 多个核心自变量（旧 demo 的加权平均关税率、NTM、TBT 等）：现在只有一个关税暴露 X，加入它们需要另外编造数据，雇主这次也没提。
- 用自定义模型替换报告里的主结果。
- 补下载 2016 年以前的年份。

## 11. 尚未确认的事项

1. **做哪一种版本**：最小版本（现有数据，固定效应差异明显，控制变量与滞后用于检验稳健性），还是完整版本（数据 v9，所有数字重算）？
2. **“滞后项”的含义**：指 X 和控制变量的滞后（可以做），还是 Y 的滞后（5 年数据上不建议做）？滞后 2–3 期的有限可行性是否需要先告知雇主？
3. **控制变量清单**：用截图里的 5 个模拟宏观变量（GDP、人口、贸易开放度、汇率、FDI），还是也加入按 ICIO 计算的变量（出口强度、制造业增加值占比等）？“贸易开放度”对应哪个变量？
4. **系数口径**：按原单位显示（与现在页面一致，另附标准差换算），还是像旧 demo 那样显示标准化系数？
5. **固定效应选项**：是否保留“国家×行业 FE”这一项（雇主的清单里只有国家、行业、年份）？是否允许一个都不勾？是否开放“国家×年份”“行业×年份”？
6. **开放范围**：四步都开放，还是先只在步骤 11 做样板给雇主看？
7. **报告**：自定义结果是只放在附录，还是允许学生把某个自定义结果作为本步主结果？
8. **统计量口径**：R² 报告总体 R²、组内 R² 还是两者都报？F 统计量用聚类稳健的 Wald F 是否可以？
9. **表注措辞**：旧 demo 的“显著性基于演示用近似 p 值”不再准确（现在是真实计算的聚类 p 值），按实际口径改写是否可以？
10. **是否补充更早年份的数据**（如 2011–2015），以增加加税前的年份？
11. **是否先做可点的样板**给雇主确认，再全面实施？
