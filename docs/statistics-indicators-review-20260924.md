## S24-01：当前模拟设计的置信区间存在可复现的覆盖不足

### 证据

定位：`gvcsim/regression/estimation.py:102` 的 CR1 修正及 `:111` 的 `t(G−1)` 临界值；`gvcsim/regression/validity.py:197` 起的支持度判定；`frontend/src/regression.tsx:140` 的区间说明。

当前教学面板有 16,220 行、3,244 个实体、5 年、76 个国家聚类，其中 44 个国家存在正暴露。四项结果均返回 `status=ok`、空 `reasons`。现有“少于 12 个处理聚类即停止”只是课程门槛，注释已正确说明“达到不保证有效”；但主流程没有描述当前 X 的信息集中程度，也没有本设计的覆盖率诊断。

将 X 同时扣除实体和年份固定效应后，定义国家的信息占比为 `h_g = Σ_g x̃² / Σ x̃²`：

- 加拿大占 **27.608%**，哥斯达黎加占 **9.103%**。
- `1 / Σ h_g² = 10.219`。这是集中度描述，**不能当作修正后的自由度，也不能与课程的 12 国停止线直接比较**。
- 在生成器所描述的独立“实体×年份 + 国家×年份”均匀扰动下，加拿大约占估计量理论方差的 **40.387%**。

固定当前发布的 X 和样本，按上述噪声结构重新抽取独立 `Uniform[-1,1]` 扰动，检验当前 CR1 + `t(75)` 区间能否覆盖生成时的 β。实体基准和共同年份趋势会被固定效应吸收；噪声尺度及 β 的平移不影响这一覆盖事件，因此该条件实验适用于四项回归的共同设计。

| NumPy 实验种子 | 重复次数 | 覆盖率 | 覆盖率自身的 Monte Carlo 95% Wilson 区间 |
| --- | ---: | ---: | --- |
| 20260924 | 10,000 | **93.58%** | [93.083%, 94.044%] |
| 20260925 | 10,000 | **93.85%** | [93.362%, 94.304%] |

两次合计覆盖率 **93.715%**；区间漏掉真 β 的频率约 **6.285%**，高于标称 5%。实验计算核的第一组样本也与应用的实际估计器逐项核对了系数和标准误。

这里使用符合生成器噪声结构的新随机抽样，**没有声称运行了 20,000 个 SHA256 生成器 seed，也没有把重复固定页面 20,000 次当成抽样**。这是固定 X 下的数值实验，不是所有数据生成过程下的覆盖率证明。

### 影响与边界

“聚类标准误 + 很多观测行 + 超过处理国家数门槛”不足以保证实际覆盖率达到 95%。这与聚类推断对信息集中、杠杆及有限聚类样本敏感的研究结论一致。[Cameron–Miller，尤其第 VI 节](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015_February.pdf)、[MacKinnon–Nielsen–Webb，尤其第 4、7 节](https://arxiv.org/pdf/2205.03285)。

这不是系数实现错误：独立完整虚拟变量 OLS 和 PanelOLS 均通过核对。也不能简单说“SE 平均偏小”：第一次实验中 SE 的均方根约 3.289，已大于指定 DGP 下的理论标准差 3.209；问题涉及 studentized 统计量的有限样本分布。

当前四个主结果删除任一国家后点估计均保持负向；本发现并不证明当前方向结论翻转。长度回归删除加拿大的点估计变化约为原 SE 的 0.956 倍，值得作为敏感性说明。生产回归当前区间没有覆盖预设 β，本身也不是算法错误或覆盖不足的充分证据。

### 建议修复与验收

1. 将主页面和报告明确标为“标称 95% 的近似聚类区间”，说明国家信息集中时覆盖率可能偏离标称水平；保留单次区间不保证覆盖预设值的现有说明。
2. 为固定发布设计保留覆盖率审计、国家信息占比及删除单个国家的敏感性结果；修正 `validity.py` 文件头把有效性归结为处理聚类数的过强表述。
3. 若课程需要更接近标称覆盖率，比较 CR2/CR3 或合适的 wild cluster bootstrap，再用预先约定的实验方案验收。**不要直接把 10.219 填进 t 分布、为了覆盖预设值选 seed，或把区间机械放大某个比例。**

## S24-02：后向长度的零最终需求边界解释错误

定位：`frontend/src/labs/steps/indicator/icio-experiment.tsx:113`，尤其 `:116`；相关测试夹具在 `icio-experiment.test.tsx:20`。

### 真实浏览器复现

1. 进入步骤 4，选择“国内生产与吸收”。
2. 点击“后向：从最终产品回溯”，加工行业正确显示 `(40 × 2 + 60 × 1) ÷ 100 = 1.4`。
3. 再点击表中的“甲国·初级品”。该行业只出售中间品，最终需求为 0。
4. 页面显示 **“后向长度 = —”**，随后却写 **“此值是其技术结构对应的单位产品后向长度”**。

后端 `length.py` 用 `(v′BB)_j y_j / ((v′B)_j y_j)` 表示实际最终需求对应的比值；当 `y_j=0` 时分母为 0，返回 `NaN`，API 转为 `null`，显示“—”是正确的。技术结构比值 `(v′BB)_j / (v′B)_j` 可以作为另一种假设单位最终需求量，但需要单独定义，不能把未计算的值说成已呈现。

前端夹具为没有最终需求的初级品写了 `PLy: 1`；实际教学 API 的同一“复杂全球价值链”场景返回 `PLy: null`。这个不一致解释了为什么现有组件测试没有覆盖真实边界。

### 建议修复与验收

把分母为零的说明改为“该行业没有实际最终需求，因此本场景后向长度未定义；请选择最终产品行业”。同步修正夹具并补测后向视角下再次选择初级品的操作。如果以后展示假设单位产品长度，应新增明确区分的数值和标签。

本轮新增后端独立边界测试已经确认 `PLv=2`、`PLy=null`、加工行业 `PLy=1.4`；未更改产品行为。

截图：`dogfood-output/statistics-review-20260924/zero-final-demand-length.png`；页面文本：`step4-zero-final-demand.txt`。

## S24-03：极小 p 值显示为零

定位：`frontend/src/regression.tsx:180` 的 `p.toFixed(3)`；`frontend/src/viz/regression/charts.tsx` 的同类 tooltip 格式化。报告的 `gvcsim/report_common.py:109` 已使用 `<0.0001`，两种呈现不一致。

步骤 11 实际重新计算并展开“计算方法说明”：原始 p 为 **2.7231 × 10⁻²⁴**，表格显示 **`0.000`**。其余三项 p 分别约为 3.28×10⁻¹⁴、3.58×10⁻¹¹、3.69×10⁻³²，也会舍入为零。

这不影响系数、CI 或显著性判断，但在统计教学中容易让学生把有限精度输出理解为精确零。建议统一使用 `<0.001` 或科学记数法，并在需要时提供原始精度。p 值也不应被解释为零假设为真的概率或效应大小；当前系统主要依靠效应量和 CI 的表达方向是合理的。[ASA p-value statement](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf)

验收应同时覆盖表格、图提示和报告的 `null`、普通 p 值及极小正 p 值，避免把数值下溢的 0 宣称为数学意义上的零概率。

截图：`dogfood-output/statistics-review-20260924/p-value-rounds-to-zero.png`；页面文本：`step11-browser.txt`。

### 独立 IO 路径对照

新增 oracle 为 3 国 × 2 行业生成稳定、正值的小系统，按供应路径依次推进，每条路径记来源 VA、最终产品行业、跨境数以及经过的生产节点数。累计 60 阶路径，余项小于 `1e-28`，再分别沿来源和最终产品方向汇总。

该算法不调用正式分解的 L、AF 或 GVC 闭式表达式。4 个独立小系统中，12 项生产量、8 项长度和国家长度加权与正式实现一致，相对容差 `1e-12`。同时验证货币单位放大/缩小时金额同比变化，长度与份额不变。

## 需要讲清、但不判为算法错误的事项

### R² 的定义

应用计算 `1 − RSS / Σỹ²`，其中 ỹ 已同时扣除实体与年份效应，表示给定两组 FE 后 X 的解释程度。PanelOLS 的 `rsquared_within` 字段仅移除实体效应，二者不可直接比较。例如贸易模型分别为 **0.139058** 和 **0.067069**。[linearmodels 官方定义](https://bashtage.github.io/linearmodels/panel/mathematical-formula.html)、[结果对象实现](https://bashtage.github.io/linearmodels/_modules/linearmodels/panel/results.html)。

当前 benchmark 只核对 β/SE，没有错误地宣称 R² 也通过对照。但界面只写“组内 R²”，建议增加一句“同时扣除实体和年份效应后的解释比例”，降低学生与其他软件输出对照时的混淆。

### 四个区间是分别的区间

四项 95% CI 不组成联合 95% 置信带。当前页面没有宣称它们是联合区间，因此不列为缺陷。若课程增加“从多个结果挑显著项”或整体假设检验，应另外讲清多重比较及预先指定结果。

### 源表精度与独立对账

这轮直接读取五份 OECD 原始宽表，不经过应用的 IO loader。使用跨国 Z/Y 逐行求和作直接出口参照，读取原始 VA 和 OUT 账户作对照。结果如下，金额单位均为百万美元：

| 年份 | 原始 OUT 与 Z 行和 + Y 行和的最大绝对差 | 六项分解加总与直接出口的最大绝对差 |
| --- | ---: | ---: |
| 2016 | 0.5113 | 0.205479 |
| 2017 | 0.8691 | 0.091903 |
| 2018 | 0.4945 | 0.097581 |
| 2019 | 0.4724 | 0.473062 |
| 2020 | 0.5828 | 0.241971 |

这里存在**源账户不平衡及其传播**，没有证据把全部差额归因于最终 CSV 四位小数舍入，也不应宣称外部原始账户机器精度闭合。它们没有触发项目已有“绝对差 > 1 且缩放相对差 > 1%”的双阈值门禁；2019 年原始 OUT 的最大缩放相对差为 1.1%，绝对差仍很小。最初用更紧的临时对账断言检查时捕获了这些差异，复核既有 QC 后将其改为明确记录，而非把它们误报为代码错误。

发布 SVA 与原始 VA 的最大绝对差约 `5.2e-9`；发布表内部生产分解最大缩放闭合误差约 `1.05e-14`；国家长度与独立行业金额加权的最大绝对差约 `3.8e-15`。五年国家/行业派生份额与各自正分母规则一致。内部恒等式和外部原始账户对账是不同层次的证据。

未完成 OECD 官方 TiVA API 序列逐口径数值对表；尤其不能用这些结果宣称项目 WWZ FVA 等同于 TiVA EXGR_FVA。
