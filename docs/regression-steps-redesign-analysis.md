## 1. 现状

### 1.1 数据流

```
OECD ICIO 真实表 ──► panel_industry.csv（真实指标，国家×行业×年）
                    ──► export_exposure_{年}.csv（真实双边出口份额）
                                │
                                ▼  gvcsim/regression/teaching.py  build_teaching_panel()
                       panel_teaching.csv（随 release 一次性生成，固定 seed 20260913）
                       X = w[c,s,USA,首年] × τ[c,t]
                       Y_k = 首年真实指标排名校准的基线 + β_k·X + 扰动
                                │
                                ▼  步骤 10 读 X；步骤 11–14 各读一个 Y_k，跑同一个 TWFE
```

- **X**：`w` 是该国家×行业首年销往美国的真实出口份额；`τ` 是虚构税率路径 `(0, 0, 0.10, 0.10, 0.10)`；加税国家由 `sha256(国家代码) < 0.60` 固定决定，当前 release 下 76 国中 44 国加税、32 国不加税（美国自身 w = 0，永远是对照）。
- **Y**：四个 Y 分别以 `FVA_share`、`3b_VA_GVC_C_share`、`PLv_GVC`、`betweenesscentrality` 的首年排名校准到可读区间，再加预设 `β = (−0.55, −0.40, −1.8, −6000)` 和固定尺度的哈希扰动；互相独立。
- **估计**：唯一公开参数是 `outcome`；服务端固定 `Y_it = β·X_it + α_i + λ_t + ε_it`，国家×行业粒度，无控制项，按国家聚类，排除 ROW。
- **报告**：保存的 run 必须带 `study_contract = economics-v2` 和 `model_snapshot.version = step10-tariff-teaching-v2`；步骤 15 汇总表按四个 outcome 各一行。
- **设计基准**：`scripts/benchmark_teaching_design.py` 用 200 个配对 seed 评估过方案（覆盖率 92.5%–97%，功效 100%，零效应误报 3%–7.5%），证明"不是靠挑 seed 得到显著"。改动生成规则必须重跑它。
- **留在代码里但不在学生路径上的**：按真实事件编码的关税目录（`shock_catalog.py`，14 个事件）和真实 Y 对真实 `tariff_shock` 的回归路径；PR #56 把它们从学生界面撤下（技术手册 15.3 也说明旧 DID／事件研究审查已删除）。按我的判断不宜恢复：2018–2020 的真实关税叠加疫情年，TWFE 识别不出稳定方向。

### 1.3 效应有多"看得见"

按当前 release 的 `panel_teaching.csv` 实算（3,244 个单元 × 5 年）：

| 项目 | 数值 |
| --- | --- |
| 加税国家单元在政策年的 X | 中位数 0.72 个百分点，均值 1.17，p90 2.71；39% 的单元 X < 0.5 个百分点 |
| 销往美国的出口份额 w | 中位数 7.2%，p90 27% |
| β·X 的平均效应 ÷ Y 的个体内标准差 | 贸易 1.2，生产 1.1，长度 0.8，网络 1.2 |
| 两组均值图上加税后的差距 | 贸易 −0.69 个百分点、生产 −0.39、长度 −0.02、网络 −63 |

统计上功效 100%，但图上只是"两条线稍微分开一点"。原因不在 β 而在 X 太小：τ 只有 10%，w 又是销往美国的份额，多数国家-行业只有百分之几。

## 2. 诊断

1. **公式不是问题。** `Y_it = β·X_it + α_i + λ_t + ε_it` 是面板政策分析最通用的骨架；二值 DID、事件研究都是它的特例或扩展。本项目里 X = w × τ × 加税后，所以它等价于按出口份额加权的 DID。不应退回一元回归（会把各国原有水平差异算进 β），也不需要更复杂的方法。
2. **问题在讲法。** 方程折叠在"可选"里，学生看到的是三格变量事实和一堆免责声明；两组均值图是最好的图解，却只有一段灰字说明，没有和 β 对上。
3. **关税看不出来。** 1.3 节的数字说明效应在图上不明显；"44 国按哈希加税、全部 10%、只对美国"也让学生觉得关税是"固定的几个国家的事"。
4. **四个回归页是一页复制四次。** 四个"本步重点"（读数、读区间、读单位、不比大小）是对的，但页面形态没有体现递进，学生只是点四次按钮。
5. **步骤 10 顺序反了。** 先抽象定义，再折叠算例，最后才看图；学生最先需要的是看到 X 在加税那年跳起来，再用自己看的那两行算一次 X。
6. **自由度为零是有意的**（防止"调到显著"）。加"换 Y"必须保持这一点：换的是问题，不是能显著的设定。

## 3. 方案：做减法

### 3.1 公式保持不变，常驻显示并逐项解释

```
Y_it = β · X_it + α_i + λ_t + ε_it
```

| 项 | 一句话 |
| --- | --- |
| `Y` | 结果变量（本步看的指标，教学模拟） |
| `X` | 关税暴露 = 冲击前出口份额 w × 模拟税率 τ |
| `β` | 要估的数：X 每增加 1 个百分点，Y 平均变化多少 |
| `α_i` | 每个国家×行业自己的起点，扣掉 |
| `λ_t` | 所有单位共同的年份变化，扣掉 |
| `ε` | 剩下的扰动；标准误按国家聚类 |

方程从"可选"折叠里移到两组均值图旁边常驻；图解对应：`λ_t` 是两条线共同的起伏，`β` 是加税后两条线分开的距离。

### 3.2 关税调到肉眼可见

只改生成参数，不改生成规则和估计器：

- 模拟税率从 10% 提到 **25%**（X 放大 2.5 倍，两组图的差距从约一个标准差变为两到三个；具体值按基准脚本重跑后定）。
- 其他不动：加税国家的抽取、只对美国市场、四个 Y 的 β 符号与扰动尺度。
- 重跑 `benchmark_teaching_design.py`，把覆盖率、误报率写进技术手册 6.2；版本号升为 v3，`randomization_version` 保持 v1（不重新抽国家）。
- 步骤 10 页面文案、任务卡（`steps.py`）和实验手册中写死的"10%"随参数改写；理解题用的是独立算例（0.25 × 0.20），不受影响。

### 3.3 步骤 10 改成一屏

1. 先出图：所选两国（默认一个加税、一个不加税）同一行业的 X 五年折线，税率起跳的那年标注。
2. 图下一句算式：用学生正看的那行数据算一次 `X = w × τ`（替代现在独立的 0.25 × 0.20 算例）。
3. 一句话说后面四步要用 X 解释什么。
4. 删掉"X 与 Y 两个变量"卡片；逐年表折叠；两国选择器改用步骤 6–9 的"国家 A + 对比国家"组件（`viz-phase0` 合并后可直接复用），允许只看一个加税国家。

### 3.4 步骤 11–14 一个模板、三段

1. **图**：两组均值变化图，配三句读图卡（加税前差不多 → 加税后分开 → 分开多少）；方程常驻在图旁。
2. **算**：按钮"算出这个差距"；结果一句话："X 每增加 1 个百分点，Y 平均变化 β，95% 区间 […]，区间是否跨零"，下面是 3.4.1 的两张图。运行后把 β 换算成"图上的差距"画回两组图，让数和图对上。按钮放在图的右上角，结果就近出现并自动滚入。
3. **不能这样写**：一句。方程细节、系数表、p 值、N 全部折叠；三处重复的免责声明合并为结果卡里的一处。

四步只换 Y 与那句读图的措辞，"本步重点"保留；步骤 14 末尾把现在只在步骤 15 出现的"四步结果汇总"表（`regression-teach.tsx` 的 `RegressionEvidenceMatrix`）提前到页面上，并配上一张四个系数并排的点加区间图（新增，四个小面板各自的轴，因为单位不同），作为四步的收尾。可选的小动作："先猜再算"（运行前点一下预计方向），零成本但有参与感。

#### 3.4.1 回归之后的图表（雇主要求的重点）

现状：结果卡里是一张"条形 + 95% 区间 + 零线"的系数图（`CoefForestChart`），条形从 0 画到点估计，颜色按正负区分。业内看得懂，但有两处不合惯例：系数图的惯例是**点 + 横向区间线**，不画条形（条形会把"从 0 到 β 的面积"读成大小，即所谓 dynamite plot）；颜色惯例是一种颜色，正负看位置。而且只有一个系数时，这张图只回答"区间是否跨零"，不回答"回归在量什么"。

建议用两张业内标准图，各管一件事：

| 图 | 回答什么 | 业内叫法 | 做法 |
| --- | --- | --- | --- |
| 分箱散点 + 回归线 | 回归在量什么：X 越大，Y 平均怎样变；线的斜率就是 β | binned scatter（binscatter），应用经济学展示单一 X 回归关系的标准图 | X、Y 先按固定效应双向去均值，X 分 20 箱，画每箱 Y 均值的点，再画斜率为 β 的直线；横轴 X（个百分点），纵轴 Y 的变化（本步单位） |
| 点 + 区间 | 这个 β 有多确定 | coefficient plot / forest plot | 现有系数图改画法：点代替条形，一种颜色，零线标"无效应"，区间两端标数值 |

分箱散点就是学生在教科书里见过的"一堆点 + 一条线"，与公式 `Y = β·X + …` 直接对应，读法是"线向下倾斜，X 每增加 1 个百分点 Y 平均下降 β"；放在结果卡第一位，系数图第二位，两组均值图保留在按钮上方作为背景。

实现：
- 后端 `/api/regression/run` 的结果多返回 20 个箱的 `(x_mean, y_mean, n)`，在 `panel.py` 现有双向去均值之后计算；不进 `model_snapshot`。
- 前端新增一个约 120 行的 SVG 组件（复用 `niceDomain` 与共享悬停层）；`CoefForestChart` 只改画法。
- 报告 `report-renderer.tsx` 已支持 `coefficient` 图，增加 `binscatter` 类型即可，步骤 15 同样放这两张。
- 四个系数并排的图是新增的：四个 β 单位不同，不能放在同一条轴上，做成四个小面板各自的轴；步骤 15 的汇总表旁同样放一张。

不建议：事件研究图（一刀切的税率路径下没有意义）；把 p 值或显著性星号画进图里（课程一直在避免"显著就是有影响"的误读，图上保留区间即可）。

### 3.5 "Y 可以换"：只在同一家族内

每个回归页加一个下拉，Y 只能换成该步骤对应指标家族里的另一个真实指标作为生成基线；服务端用同一生成规则现算模拟 Y 并回归，页面形态不变。

| 步骤 | 固定 Y 的基线 | 可选基线 |
| --- | --- | --- |
| 11 贸易 | `FVA_share` | `DVAex_share`、FDC 占总出口比重（需新增派生份额） |
| 12 生产 | `3b_VA_GVC_C_share` | `3_VA_GVC_share`、`3a_VA_GVC_S_share`、`1_VA_D_share` |
| 13 长度 | `PLv_GVC` | `PLy_GVC`、`GVCPs` |
| 14 网络 | `betweenesscentrality` | `weighted degree`、`closnesscentrality` |

- 每个可选基线要有自己的 β 与校准区间：方向由雇主给，幅度按基准脚本定并公开在技术手册。
- 报告记录学生最后跑的那一个（`model_snapshot` 多记基线指标），汇总表仍四行；门槛不变。
- 不做情景选择、不做模型选项、不做"自选题"小节。

### 3.6 明确不做的

- 分批实施、多市场、行业定向、反制等关税情景。
- 二值 DID、事件研究、控制变量、自由粒度。
- 真实事件回归（识别不住，见 1.1）。
- 揭晓真值与反事实：有教学价值，但多一层概念；等简单版上线后若雇主想讲"回归为什么是对的"再加。
