### E01 — 支持度必须由实际参与 ATT 的配对样本决定

位置：[validity.py:158](../gvcsim/regression/validity.py#L158)、[panel.py:1550](../gvcsim/regression/panel.py#L1550)、[panel.py:1951](../gvcsim/regression/panel.py#L1951)。

`analyze_support()` 把有处理后记录的国家计入处理聚类数；真正计算 ATT 时，`_prepare_cohort_time_cells()` 又要求同一实体在 `g−1` 和目标期均有结果值，并删除不能配对的实体。两套样本没有同步。动态方法另分别统计基期与事件期的国家数，但两边各自足够也不意味着交集足够。

复现结果：DID 面板有 20 个名义处理国家，其中 18 个缺少基期结果。真正用于每个 ATT 单元的处理国家只有 2 个，返回却是 `status=ok`、`treated_clusters=20`、`benchmark_passed=true`。两个随机种子得到 p≈`3.67e-36` 与 `8.01e-28`，均显示三星。动态反例让基期、处理后各有 16 个国家，但实际配对交集只有 2 个，也能发布处理后区间。

这里不是讨论“12 是否是完美阈值”，而是系统没有执行自己声明的门槛。少数有效处理聚类不能由大量无贡献国家补足；算术复核通过也不能确认支持度正确。[MacKinnon & Webb 的原始研究](https://www.econ.queensu.ca/sites/econ.queensu.ca/files/qed_wp_1364.pdf)讨论了少处理聚类下常规聚类推断的失效。

**建议**：先构造实际 cohort×时期配对集合，再由这些集合生成总体和逐期支持度、样本量及聚类贡献诊断。动态结果必须核对基期与目标期配对的交集；同时处理有效对照侧不足。支持不足时保留清楚标注的点估计并抑制推断，前端、报告门禁和预检共用最终诊断。复现脚本应转为“必须抑制”的回归测试。

边界：此问题在合成缺失模式下得到确认。本次正式 release 的 63 种公开组合复跑未复现“总体实际仅 2 个处理国家”的同一缺陷，不能据此宣称已有全部课堂结果都被该缺陷影响。

### E02 — FVA 与 OECD 的差异不止 TLS

位置：[indicator_schema.py:140](../gvcsim/indicator_schema.py#L140)、[tradeflow.py:106](../gvcsim/indicators/tradeflow.py#L106)、[regression-lessons.ts:53](../frontend/src/regression-lessons.ts#L53)、[quizzes.py:61](../gvcsim/quizzes.py#L61)、[teaching_report.py:1752](../gvcsim/teaching_report.py#L1752)。

课程正确说明自己使用 WWZ 五类聚合项加 TLS 扩展，但又把 FVA 解释成毛出口中由“所有外国直接与间接上游”创造的纯增加值，并反复将与 OECD 指标的区别归因为 TLS 单列。这漏掉了 **WWZ 的 FDC 与 gross-export foreign content 的关系**。

[OECD TiVA 2023 指南](https://www.oecd.org/content/dam/oecd/en/topics/policy-sub-issues/trade-in-value-added/tiva-indicators-guide-2023.pdf)第 12、22、37 页给出 VA 的税收口径、EXGR_FVA/FVASH 与 `V̂ B EXGR` 的定义。[WWZ 原文](https://www.nber.org/system/files/working_papers/w19677/revisions/w19677.rev0.pdf)区分外国增加值项与外国纯重复计算项。根据这两套定义，对当前代码可直接推出：

\[
FVA^{gross,pureVA}_s
=\Big(\sum_{r\ne s}v_r B_{rs}\Big)\odot E_s
=FVA^{WWZ}_s+FDC^{WWZ}_s.
\]

这是本次的代数核对，不是把一个现成 OECD 数列下载后强行对齐。即使 **TLS=0**，两套 FVA 仍可不同：零税两国算例中，课程份额为 10.857% 与 24%，同一出口的外国 `vB` 含量为 16% 与 36%；把全部金额放大 7 倍后差异不变。

正式 2020 产物中，补回 FDC、仍不加入外国 TLS 后，中国为 11.730%→14.529%，德国为 15.613%→20.538%，美国为 5.510%→7.206%；77 个账户的差距中位数约 4.352 个百分点。**这些补回值也不是官方 EXGR_FVASH**，因为尚未对齐官方 VA+TLS、版本及其他编制细节。

**建议**：保留 WWZ 分解里的 FVA/FDC 两项，明确标注 FVA 是该分解中不含 FDC 的外国增加值项；需要讲 OECD 后向参与时另设定义完整的指标。解释与 OECD 的差异时同时说明重复计算和税收处理。同步修改题目反馈、图表说明、回归因变量释义和报告，不能只改一个 tooltip。若改变回归分子，应作为新的指标/数据版本发布，不悄悄改写旧报告含义。

### E03 — 超过阈值不等于第一次受到政策影响

位置：[shock_catalog.py:11](../gvcsim/shock_catalog.py#L11)、[shocks.py:580](../gvcsim/shocks.py#L580)、[panel.py:1487](../gvcsim/regression/panel.py#L1487)、[regression-lessons.ts:38](../frontend/src/regression-lessons.ts#L38)。

处理标记是 `tariff_shock > 0.001`，即行业全部出口的平均额外暴露超过 0.1 个百分点。之后 `G_i` 取该标记首次为 1 的年份。报告已披露 treated 是课程阈值标记，但课程问句和模型说明仍使用“从未/尚未受冲击”“首次冲击前一年”。这会把低暴露误教成无暴露，把越过阈值误教成政策启动。

当前数据已触发：行业面板 210 个曾越过阈值的实体中，5 个在 `g−1` 已有正关税暴露；另有 173 个“从未越过阈值但暴露为正”的实体年。国家面板也有 2 个已暴露基期和 180 个此类对照年。例如德国被编入 2020 cohort，但 2019 年已有约 0.06596 个百分点暴露；中国农业行业在其 2019 cohort 的基期已有约 0.09554 个百分点暴露。

[Callaway、Goodman-Bacon 与 Sant’Anna 的连续处理研究](https://arxiv.org/abs/2107.02637)说明，剂量变化不能自动获得与二元首次处理同样的解释。二元代码没有解决阈值以下政策影响和基期可比性。

**建议**：明确选择估计对象。若教学对象是首次政策启动，用政策历史定义时点，并针对预期效应、低强度暴露和对照污染作诊断；若保留阈值，统一称“首次越过教学阈值”，显式展示基期正暴露及低暴露对照，避免把结果解释成从无政策到有政策的因果 ATT。阈值敏感性应比较支持集合与估计对象，而不只是比较 p 值。

### E04 — “撤销少于 5%”不能保证吸收型 ATT 只略有偏离

位置：[validity.py:24](../gvcsim/regression/validity.py#L24)、[validity.py:202](../gvcsim/regression/validity.py#L202)。

系统发现撤销后，如果其占处理后实体年的比例低于 5%，仍展示区间，并称估计对象“略有偏离”。[Callaway & Sant’Anna 原文](https://arxiv.org/pdf/1803.09015)Assumption 1 要求处理不可逆。撤销行数占比本身没有给出效应偏差界限，尤其对无固定上界的长度、中心性结果如此。

默认行业关税样本撤销比例约 0.4983%，所以该分支正在使用。合成反例维持同样的 1/60≈1.667% 撤销比例、正常在场效应 0.1；只改变撤销后的结果响应，总体点估计可从约 0.265 变为 1.765，两者都仍是 `warning` 且有区间。这个反例不声称量化了正式数据的偏差；它否定的是“撤销比例小就能断定影响小”的逻辑。

**建议**：若坚持持续政策暴露的 ATT，应对不相容的路径停止该解释，或采用明确支持非吸收型处理的方法。也可以重新定义为“首次暴露后的整段历史效应”，但必须说明含撤销、残留效应和政策路径，不能沿用持续处理的解释。任何删去撤销后时期的方案还需说明选择与目标总体变化。连续强度 TWFE 能跟随路径变化，但本身仍是描述性关联，不是自动恢复因果识别的办法。

### E05 — 复杂 GVC 不要求两次都以中间品形式跨境

位置：[indicator_schema.py:149](../gvcsim/indicator_schema.py#L149)、[indicator_schema.py:155](../gvcsim/indicator_schema.py#L155)。

[WWYZ 参与度论文](https://www.nber.org/system/files/working_papers/w23222/w23222.pdf)第 6 页明确包括：中间品被进口国用于生产再次出口的产品，第二次出口可以是中间品，也可以是最终品。

代码本身能够正确处理这一路径：A 向 B 提供 20 单位中间品，B 把最终品卖给 C；A 的这 20 单位增加值被归为复杂 GVC，简单 GVC 为 0，前向 GVC 长度为 2。三倍规模复测相同。当前“中间品至少两次跨境”的 tooltip 会使学生把正确计算结果理解错。

**建议替换定义**：“至少一次以中间品形式跨境，并在最终吸收前累计跨境两次及以上；后续跨境可以由中间品或最终品承载。”在简单/复杂对比中加入这一算例，前向、后向释义一并修正。

### E06 — 分类对应不应教成按上游部件任意分摊

位置：[crosswalk.py:127](../gvcsim/data/crosswalk.py#L127)、[crosswalk.py:146](../gvcsim/data/crosswalk.py#L146)、[crosswalk.py:218](../gvcsim/data/crosswalk.py#L218)。

当前统一把 HS01–03 映射为农业 75%、渔业 25%。这使 HS01 活动物含 25% 渔业，也使 HS03 鱼类水产品含 75% 农林畜牧。HS01 与 HS03 的范围可直接查 [WCO 2017 章目](https://www.wcotradetools.org/en/harmonized-system/2017/en/01)，行业区分可查 [UN ISIC Rev.4](https://unstats.un.org/unsd/demographic-social/census/documents/isic_rev4.pdf)。此外，若干映射以“上游木浆”“矿物投入”“电气部件”为分摊理由，容易把产品所属生产行业与投入产出传导混为一谈。

一对多对应可以存在，权重也可以用于教学模拟，但应对应章内不同产品的生产行业构成；不能仅因某产品使用某投入，就把商品关税直接分给该上游行业。[美国 Census 的 HS—行业对应方法](https://www2.census.gov/ces/wp/2009/CES-WP-09-41.pdf)将产品与其生产行业相联系。

**建议**：使用少量可核对的 HS6—ISIC—ICIO 示例；把直接商品映射和后续经 `A/B` 的上游暴露传导分开。保留章 77 不应为了“97/97 覆盖”而赋予金属贸易权重。现有四项 QC 只检查覆盖、权重和与值域，不应产生专业分类已验证的印象。

另需澄清 `avg_tariff` 的分母：当前仅来自七个示例 HS 章映射后的贸易权重，是该示例篮子的行业均值。真实行业平均税率还需纳入未列入清单的贸易额和零新增税率产品；不能直接套用为完整行业平均值。

### E07 — 配额影子成本与额外关税率混用

位置：[shock_catalog.py:341](../gvcsim/shock_catalog.py#L341)、[shock_catalog.py:64](../gvcsim/shock_catalog.py#L64)。

阿根廷、巴西、韩国的 C24 都被填入 3%，代码注释说这是配额影子成本，后续变量却统一定义为全部出口面对的平均“额外关税”。[CBP 当年配额通知](https://content.govdelivery.com/accounts/USDHSCBP/bulletins/1f6cce4)区分钢材及铝产品的绝对配额；[USITC 的 2018 专题](https://www.usitc.gov/research_and_analysis/trade_shifts_2018/special_topic.htm)还明确区分巴西、韩国的钢材配额与其铝产品税率安排。不能把它们统称为“钢铝无从价税、3% 影子成本”。

**建议**：在 `tariff_shock` 中只保留定义一致的新增从价税暴露；另设配额/非关税约束变量。若确要合成从价等值成本，应标明这是额外假设、给出校准依据并改写单位解释，不能称为法定税率或实际缴税比例。

### E08 — 欧盟政策边界与固定 EU27 集合不相容

位置：[shock_catalog.py:216](../gvcsim/shock_catalog.py#L216)、[shocks.py:277](../gvcsim/shocks.py#L277)。

2018 年欧盟对美再平衡关税使用 EU27 目的地流量，英国被排除。源码说英国另在空客案中单列，但空客案是美国对英国等经济体加税，方向与欧盟/英国对美国反制相反，不能补回美国对英国出口的暴露。

[英国 2018 年实施说明](https://www.gov.uk/government/news/eu-measures-in-response-to-us-steel-and-aluminium-tariffs)直接确认当年英国进口商适用 6 月 22 日开始的欧盟再平衡措施。这是历史政策成员范围问题，不是 OECD 统计中能否展示 EU27 这一聚合区的问题。

**建议**：政策加征方集合按事件适用范围和年份定义；至少对 2018–2019 年使用包含英国的范围，并单独核对 2020 年过渡期规则。改动会改变生成的出口暴露及冲击，应通过新数据 release 更新，而不是在旧报告中重解释数字。

### E09 — 俄罗斯能源金融事件需要先明确具体政策，再填写生效日

位置：[shock_catalog.py:539](../gvcsim/shock_catalog.py#L539)。

“OFAC/二级制裁风格：俄罗斯能源金融限制”把宣布、生效都填为 2017-08-02，没有列出对应指令或主体名单。这个日期能对应 CAATSA 成法，不能支持所有能源金融措施同日生效的教学时间线。

例如 [OFAC 2017-09-29 公告](https://ofac.treasury.gov/recent-actions/20170929)写明修订 Directives 1/2 的部分限制从 2017-11-28 生效；[OFAC FAQ 370](https://ofac.treasury.gov/faqs/370)又区分这些行业限制与 SDN 冻结，并说明更早版本始于 2014 年。当前事件到底表示新限制、既有措施强化，还是一个人为情景，缺乏足够定义。

**建议**：若只是虚构情景，在时间轴上明确标记情景起点；若要教真实事件，应指定法规/指令、法律作用和增量变化，分别记录签署、宣布、生效，并补齐来源。不能不区分具体措施就机械把日期统一改成另一个日期。本项是事件定义与证据不足的确认，不是宣称所有 CAATSA 条款都在 11 月 28 日生效。

### E10 — 动态 ATT 的公式必须限定事件时间

位置：[design.py:179](../gvcsim/regression/design.py#L179)。

`did` 与 `event_study` 只把公式左侧从 `ATT^{overall}` 换成 `ATT_k`，右侧都是对全部 `g,t` 的同一个加权求和，权重也没有事件时间索引。按展示公式理解，右侧不依赖 k，无法产生随事件时间变化的动态路径。实际估计代码按事件时间分别聚合，因此这里是公式展示与实现不一致。

**建议替换为**：

\[
\widehat{ATT}_k
=\sum_{g\in\mathcal G_k}\omega_{g,k}\widehat{ATT}(g,g+k),
\qquad
\omega_{g,k}=\frac{n^{pair}_{g,g+k}}{\sum_{h\in\mathcal G_k}n^{pair}_{h,h+k}}.
\]

其中集合只包含该事件期可估计的 cohort，基期仍为 g−1；k=−1 是归零参照，不是另一个被估计的效果。负事件期应说明是相对统一基期的处理前诊断。这个写法按本项目的实体数权重复述实现，不宣称是所有软件唯一的聚合方案；[作者的 did 文档](https://bcallaway11.github.io/did/reference/att_gt.html)也明确区分基期约定和处理前/后的解释。对照集合建议写成 `C_{g,t}`，以反映处理前诊断中代码使用的 `G>max(g,t)` 限制。

### E11 — 重复计算项的微小负号不代表经济学上的负贡献

位置：[trade.tsx:45](../frontend/src/labs/steps/indicator/trade.tsx#L45)。

“负值不是错误：DDC/FDC 本来就是重复计算类别”给出了错误的因果解释。在非负 IO 流、最终需求和增加值系数的标准假设下，重复计算项仍是非负金额贡献，而不是为闭合而相减的负项。负 TLS 可表示净补贴，应另行说明。

2020 行业表的 DDC 有 67 个负数，但最小约为 `−2.28×10^-13` 百万美元，属于应按容差处理的浮点残差，不能据此讲成经济上的负重复计算。若源账户含实质性负项，则应追溯 VA、存货等具体来源。

**建议**：改为“极小负数可能来自浮点舍入；超过容差需检查源账户与计算。TLS 为负可表示净补贴。”保持原始数据可追溯，不简单截断全部负值。

## 2. 已核对的核心公式及专业判断

令 `A=Z diag(x)⁻¹`、`B=(I−A)⁻¹`、`L` 为各国内部逆矩阵组成的块对角矩阵、`Aᶠ=A−Aᴰ`。`yᴰ/yᶠ` 分别是最终产品在生产国内吸收/向国外销售的向量；`v=VA/x`，`t=TLS/x`。表中乘法顺序不能互换。

| 内容 | 核对结果 |
|---|---|
| ICIO 行供给、列使用；Z/Y/VA/TLS/OUT | 与 OECD 数据结构一致；`OUT` 有独立源行检查，不只是用同一个 `Z+Y` 自证 |
| `x=Z·1+Y·1`，`(v+t)'B=1'` | 区分 VA 与 TLS 后的账户关系合理；TLS 不是步骤 10 的额外关税 |
| WWZ 毛出口分解 | 五类项加 taxsub 的闭合及伙伴汇总实现有测试支持；FVA 的经济释义需按 E02 修正 |
| 前向生产分解 | `v⊙L yᴰ`、`v⊙L yᶠ`、`v⊙L Aᶠ L yᴰ`、其余 GVC 部分，分别对应纯国内、传统、简单、复杂活动 |
| 后向生产分解 | 对同一增加值路径按最终产品完成地汇总，当前实现与独立路径核对一致 |
| 前向总长度 | `PLv=(B x)/x`；GVC 分子核为 `L L Aᶠ x + L Aᶠ B x`，分母核为 `L Aᶠ x` |
| 后向总长度 | `PLy=(v'B B)/(v'B)`；GVC 分子核为 `v'L L Aᶠ B + v'L Aᶠ B B`，分母核为 `v'L Aᶠ B` |
| 国家长度与 GVCPs | 国家层级先分别汇总分子、分母；不是直接平均行业比值。`GVCPs=PLv_GVC/PLy_GVC`；不是跨境次数、国家数、企业战略或经济发展等级 |
| 网络 | 国家图 Z+Y 跨境贸易，行业图完整 Z；供应方向、正边、自环双计、无权路径、未归一化介数的说明与代码一致 |
| Gephi 入边分数 | 已标为 Gephi 0.10.1 兼容分数，避免当成标准 Perron 指标；现场重新运行 Gephi golden check 逐字节通过 |
| cohort-time ATT 点估计 | 每单元以 g−1 为基期，不用已处理对象作对照；按可用处理实体数聚合，早 cohort 重复贡献已披露。问题集中于 E01/E03/E04 |
| 连续强度 TWFE | 作为描述性关联的标签合理；不等同于非参数剂量反应或政策因果效应 |
| 控制变量、ROW、置换 | 公开接口禁用同期/模拟控制，默认排除 ROW；实体置换明确不是校准 p 值，均应保留 |

生产及长度的核对依据为 [WWYZ 参与度原文](https://www.nber.org/papers/w23222)与[生产长度原文](https://www.nber.org/papers/w23261)。本次另写了不调用 `L/Aᶠ` 分解公式的路径求和程序：按中间品边数与最终吸收地分类，累计 90 阶路径，同时累计“路径权重×生产阶段数”。三个独立矩阵、前后向分解、各活动长度及国家聚合全部匹配，最大绝对误差 `7.11×10^-15`。这提供了比闭合恒等式更强的算术证据，但不等于对原始 OECD 单元格逐项认证。

[Gephi 原项目问题记录](https://github.com/gephi/gephi/issues/2145)说明为何软件兼容分数与标准特征向量中心性应区别对待。已有的正边敏感性、国家完全图退化及经济枢纽解释限制是必要披露，本轮不把这些已经明确标注的限制重复算成新缺陷。
