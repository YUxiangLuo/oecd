# 课程证据与评分契约

本文件把两件事明确分开：

1. **系统自动核验硬门槛**决定步骤是否显示完成、能否生成第 16 步报告；
2. **教师 0–2 分深度 rubric**评价学生的经济学理解、推理质量与边界意识。

硬门槛只能证明某个服务端可复现的动作、对象或运行确实存在，不能自动判定学生的经济解释一定正确。访问页面、切换标签或上传任意字符串都不构成完成。

## 一、系统自动核验硬门槛

### 通用可信证据规则

- 步骤 1、3–15 的 CER 必须包含 `claim`、`evidence`、`reasoning`、`boundary`；每段至少 12 个字符，四段不能重复，`evidence` 至少出现一个数字。
- CER 的长度、重复和数字规则只是最低结构检查。系统**不会**自动判定 Claim 是否成立、Reasoning 是否充分，或 CER 文字里的每个数字是否与数据一致；这些由教师 rubric 评分。
- 步骤 1–11 的可核查动作先由服务器重读当前数据，再写入 append-only evidence event 并签发收据。收据绑定学生账号、`assignment_id`、`attempt_id`、`manifest_id`、步骤、类型、payload 摘要和服务端事件 ID；修改筛选、观察值或 CER 后旧收据失效。
- 步骤 12–15 只认可服务器实际运行后签发的 `run_id` / `placebo_run_id`。令牌同样绑定当前学生、作业 attempt、manifest、完整回归设计和结果摘要。
- 回归步骤另需至少 15 字的识别判断。服务器检查其存在和长度，不替教师判断观点质量。

### 分步硬门槛

| 步骤 | 系统实际自动核验的最低要求 | 不属于自动判真的内容 |
|---:|---|---|
| 1 | 学生主动选择一个有效 ICIO `Z`、`Y` 或账户项切片；服务器重读原始 ICIO，并逐项核对所选 `row`、`column`、有限数值 `value` | 是否访问了全部三张表；是否正确解释 `OUT = Z + Y` |
| 2 | 选择 `stop` / `fix` / `disclose` 并提交至少 15 字理由；`fix` 必须记录修正规则且当前 manifest 复检通过；`disclose` 必须逐项包含当前 QC 的全部披露项；`stop` 阻断报告生成，界面禁用后续步骤 | 对异常影响链的解释是否充分；修正策略在研究上是否最优 |
| 3 | 指标固定为 `FVA_share`；提交两个不同经济体的国家×行业观察值，服务器按当前年度产物重算数值，并确认两国均在 `compared` 中 | 两个观察是否形成最佳可比样本；WWZ 六项加总与差异解释是否正确 |
| 4 | 指标固定为 `3b_VA_GVC_C_share`；提交两个不同经济体的国家×行业观察值并由服务器重算 | 是否正确分类具体生产路径；水平与份额的经济含义是否解释充分 |
| 5 | 指标固定为 `GVCPs`；提交两个不同经济体的国家×行业观察值并由服务器重算 | 是否完成“份额×段长度”重建；是否真正区分 `PLv`、`PLy`、`GVCPs` |
| 6 | 指标固定为 `betweenesscentrality`；提交两个不同经济体的国家×行业观察值并由服务器重算 | 小网络推演是否正确；加权度与介数的机制解释是否成立 |
| 7 | 图表必须为 `quadrant` / `decompose` / `rank`；指标为 `FVA_share` 或 `DVAex_share`；提交两个不同经济体的国家级观察值并由服务器重算 | 象限含义、反例与因果边界是否解释充分 |
| 8 | 图表必须为 `ladder` / `rank` / `industry`；指标为 `3_VA_GVC_share` 或 `3b_VA_GVC_C_share`；提交两个不同经济体的国家级观察值并由服务器重算 | 国家×行业比较或反例是否有洞察力 |
| 9 | 图表必须为 `position` / `bars` / `rank`；指标为 `PLv_GVC`、`PLy_GVC` 或 `GVCPs`；提交两个不同经济体的国家级观察值并由服务器重算 | 对上下游位置、`PLv=PLy` 或 `GVCPs=1` 的解释是否正确 |
| 10 | 图表必须为 `heat` / `network`；指标为 `betweenesscentrality` 或 `weighted degree`；提交两个不同经济体的国家×行业观察值并由服务器重算 | 高介数行业选择是否最有代表性；粒度和网络机制说明是否充分 |
| 11 | 三类冲击各保存一个已登记的具体事件；事件必须真实出现在当前 shock panel；学生确认当前 shock QC，服务器保存 QC 失败项 | 宣布/生效、强度、映射与对照组选择的经济学解释是否完整 |
| 12 | 当前贸易回归有可信 `run_id`；另有无控制 `baseline_run_id` 和有控制 `controlled_run_id`；两次设计除控制/相应价格口径外，冲击、样本、方法、情景和权重必须一致 | DID 2×2 解释、控制变量选择和因果判断是否正确 |
| 13 | 当前生产回归有可信 `run_id`；保存无交互与有交互两次同设计运行；提交至少 15 字且含数字的低/中/高基期 GVC 边际效应说明。API 同时返回按完整协方差计算的 P25/均值/P75 结构化边际效应 | 学生是否正确使用边际效应而非孤立解释交互项系数 |
| 14 | 当前长度回归必须是可信事件研究 `run_id`；事前诊断与事后效应各至少 15 字且含数字 | 是否正确理解“不显著不等于证明平行趋势”以及动态路径 |
| 15 | 当前网络回归和安慰剂均有可信令牌；两者的 outcome、粒度、冲击、方法、控制、交互、价格、情景、样本和权重完全一致；CER Boundary 必须明确提到 SUTVA、干扰或网络外溢 | 安慰剂尾部位置、标准差单位和网络干扰的实质解释是否充分 |
| 16 | `report_key` 必须对应当前学生、attempt 和 manifest 下由服务器生成的真实报告实体；报告生成前重新检查步骤 1–15，并在服务器端复估四步回归 | 教师评分、反馈和最终提交评价 |

## 二、教师 0–2 分深度 rubric

系统完成对勾只表示“达到可核查最低门槛”，不等于 2 分。每步 CER 建议按以下统一尺度评分：

- **0 分**：缺失；只有点击记录；引用对象或数值无法复现；结论明显与证据矛盾。
- **1 分**：主张和可复现数据存在，但推理、可比性或边界说明不充分。
- **2 分**：主张明确且可反驳，证据选择合理、数值可复现，推理成立，并主动说明适用边界或替代解释。

各步达到 2 分时可重点观察：

| 步骤 | 教师深度评分锚点（不是系统硬门槛） |
|---:|---|
| 1 | 主动比较 `Z`、`Y`、账户项，能解释一个单元格并用 `OUT` 核对投入产出恒等关系 |
| 2 | 点名具体失败/警告项，说明其下游影响链，并为 stop/fix/disclose 选择给出可辩护理由 |
| 3 | 使用同年同业可比对象，展示 WWZ 六项与毛出口加总关系，并解释跨国差异 |
| 4 | 同时讨论 WWYZ 水平和份额，能把一个具体生产活动归入简单/复杂 GVC 路径 |
| 5 | 完成一次“份额×段长度”重建，清楚区分前向长度、后向长度和 GVC 位置 |
| 6 | 先在小网络中推演度/介数，再用真实数据解释为何加权度与介数可能分离 |
| 7 | 引用实际坐标和两个经济体，正确解释象限，并指出至少一个口径或因果限制 |
| 8 | 给出有意义的国家×行业对比或反例，不把国家汇总变化误当作所有行业一致变化 |
| 9 | 用数值说明上下游位置，正确讨论 `PLv=PLy` 或 `GVCPs=1` 的边界情形 |
| 10 | 为两个国家各找出代表性高介数行业，并说明国家级完全图与国家×行业图的粒度差异 |
| 11 | 逐类说明事件的宣布/生效、受处理行、强度、映射/QC 和对照组可比性 |
| 12 | 正确讲清 DID 2×2 比较，解释加入控制后变化，并讨论平行趋势、处理支持和权重口径 |
| 13 | 用 P25/均值/P75 的实际边际效应及不确定性解释异质性，不把交互项本身当作任意个体效应 |
| 14 | 同时引用事前联合诊断与事后动态系数，不把“未拒绝”写成“假设已证明” |
| 15 | 将真实估计与同设计安慰剂分布比较，并讨论标准差单位、SUTVA 破坏和网络外溢 |
| 16 | 报告中的主张、证据、回归设计、QC 披露和限制前后一致，能够由 provenance 复现 |

统计显著性本身不加分。正确识别设计不足、在 QC 为 `stop` 时拒绝继续、或主动避免过度因果解释，应视为高质量表现。
