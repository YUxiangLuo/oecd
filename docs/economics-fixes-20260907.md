报告完成规则一并修正：完整的支持不足或设计不相容诊断可以完成对应材料要求；不会强迫学生寻找显著或可推断模型。没有任何可估计配对时返回明确诊断、空系数、零实际样本量和空均值/标准差，不制造零效应。报告主表采用各步最新的完整估计或诊断，先前可推断快照仅供对照；缺损或与停止推断状态相矛盾的载荷仍不被接受。

另补充了 ICIO 的统计编制性质、增加值所在地与企业所有权的区别、逐项区间与同时置信带的区别，以及四步证据表中的冲击、方法、粒度、场景和权重。16 条政策事件现在都有来源链接；来源仅覆盖部分主张的事件继续标为部分来源，年度行业强度仍不冒充官方观测。

- 新产物通过哈希、结构、原始数据绑定及完整发布门禁；性能结果见 [v12 基准](../benchmarks/shock_panel_v12.json)。
