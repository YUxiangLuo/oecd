**R01：排除“已经通过其他规则豁免”和“只是教学税率不精确”两种解释。**

当前 [shock_catalog.py:344](../gvcsim/shock_catalog.py#L344) 的 201 事件没有加拿大豁免或覆盖；执行循环也没有额外排除。洗衣机 Proclamation 9694 执行条款第 2 项明确排除加拿大产品。[美国原始公告](https://www.govinfo.gov/content/pkg/FR-2018-01-25/html/2018-01604.htm)。

直接读取原始 ICIO，按国家归集跨境中间品与最终需求，构建完整 C27 出口目的地表，再调用当前 `demo_shock_panel`：

| 加拿大 C27 | 2018 | 2019 | 2020 |
|---|---:|---:|---:|
| 当前固定权重冲击 | 0.019155701 | 0.016601608 | 0.014047514 |
| 当前 treated | 1 | 1 | 1 |
| 仅在内存补入加拿大 C27 豁免后的冲击 | 0 | 0 | 0 |
| 补入豁免后的 treated | 0 | 0 | 0 |

其他事件未改动，说明没有另一事件能够解释该实体的正冲击。这里确认的是国家–行业实体被错误纳入 2018 cohort；不能据此声称加拿大国家级 cohort 一定改变，因为国家级还可能受到其他行业政策影响。

同时修正首轮论证：`source_complete=True` 并不担保教学行业映射、覆盖率或强度为官方数值，其披露已明确限定。保留问题的依据是**真实政策排除范围与生成器处理对象冲突**，并非教学税率没有达到实测精度。上述数字均为教学编码结果。

**R02：用完整虚拟变量回归独立复核，并测试不会误拒的样本。**

从相同完整案例样本构造截距、冲击、国家/实体虚拟变量和年份虚拟变量，用 `numpy.linalg.lstsq` 求解，再按国家聚合 (X_g'u_g) 构造 CR1 协方差。该参考计算没有调用项目的去均值函数，也没有复用 PanelOLS 的协方差。

| 样本 | 自写 SE | 独立虚拟变量 CR1 SE | 当前 PanelOLS SE | 当前结果 → 统一修正后 |
|---|---:|---:|---:|---|
| 20 国，平衡，100 行 | 0.181684583 | 0.181684583 | 0.177976345 | invalid_design → ok |
| 20 国，不平衡，93 行 | 0.205904833 | 0.205904833 | 0.201778972 | invalid_design → ok |
| 20 国 × 3 行业，300 行 | 0.090132761 | 0.090132761 | 0.087997333 | invalid_design → ok |
| 76 国，平衡，380 行 | 0.077567778 | 0.077567778 | 0.077157364 | ok → ok |

自写与独立虚拟变量结果最大 SE 差异约 (2.96\times10^{-12})。不同引擎的 SE 比值吻合：

\[
\sqrt{\frac{G}{G-1}\frac{N-1}{N}}。
\]

仅在内存中的 PanelOLS 调用加入 `group_debias=True` 后，对照差异降至约 (2.96\times10^{-12}) 以下，全部通过。该组数修正及其默认关闭状态也与[官方协方差文档](https://bashtage.github.io/linearmodels/panel/panel/linearmodels.panel.covariance.ClusteredCovariance.html)一致。

因此问题是 [panel.py:1804](../gvcsim/regression/panel.py#L1804) 与自写实现采用不同约定，却据此宣布设计无效。它不证明自写 CR1 公式错，也不保证小聚类样本的推断充分可靠。

**影响收窄：默认 DID/事件研究走 cohort-time 分支，不调用该 PanelOLS 对照；当前 76 国样本量级通常未超过 2% 阈值。**本次没有证实正式 v12 公共回归已因这一问题被拒绝。20 国等合成样本的误拒是真实反例，覆盖国家与行业粒度、不平衡数据，但不能冒充正式数据的失败记录。

**R03：由合成边界扩展到当前五年原始数据，确认实际触发。**

重读 2016–2020 原始 CSV，独立按目的地汇总 Z+Y，剔除国内交易、按项目约定裁剪负目的地净流量，重建 1,351,350 行暴露表。EU 复合行按当前成员规则计算；没有读取旧 release 的出口暴露列。

将完整 C24 目的地表分别传给未修改的生成器：固定模式中的 `tariff_shock_contemporaneous` 为 0，当期模式中的同名列与上表非零值逐一吻合，且两个输出恰好相差这 8 行。[shocks.py:555](../gvcsim/shocks.py#L555) 的提前跳过是直接原因。

这里**固定基期主冲击为 0 是正确的**；错误只在另一个当期列也被跳过。公开 `_panel_for_weight_mode` 会直接把该列作为稳健性回归的冲击，因此无法在读取时修复遗漏。新增的“正→零、正→正、零→零”合成对照均正常，只有“零→正”异常。

这些份额来自项目教学关税目录，不能解释为实测关税或同量级的国家 GDP 影响；也不代表本次已经核验远程发布产物。

**R04 与 R05：分开处理额外假设和确定的粒度错误。**

R04 的 1,000 倍比较成立的前提是，把模拟式里的规模因子视作百万美元到美元的换算。但 [citations.py:23](../gvcsim/data/citations.py#L23) 的契约明确允许对 SVA 作确定性教学变换，并标记 `production_data=False`。首轮把这个额外前提写成了确定事实，证据不足，现予撤回。仍建议说明模拟经济规模的目标与校准方法；本次不主张直接改系数。

R05 则有不依赖模拟规模的反例：2016 两行业为 10、90，2017 为 20、90，平减指数由 1 变为 1.1，全国实际金额两年均为 100，增长率应为 0。输入每次均先 `reset_index(drop=True)`，a 行业在前得到 81.818%，b 行业在前得到 −9.091%。先加总为国家表再调用同一辅助函数则得到约 0，排除了索引错位与增长定义不同的解释。

直接调用当前公开参数校验：`none + nominal` 通过，`icio_derived`、`macro_sim` 和 `none + real_2016` 均返回 400。因此 R05 为确认的内部辅助缺陷，优先级由 P2 调整为 P3；R04、R05 均不应表述为默认 ATT 已受污染。
